# User documentation images

Screenshots for the **User Documentation** section (`docs/user/`).

- Reference them from Markdown with a leading `/`, dropping `static`:
  `![Connect wallet](/qday/user/01-connect-wallet.png)`
- Naming: lowercase-kebab, number-prefixed for step order — e.g.
  `01-connect-wallet.png`, `02-claim-faucet.png`.
- English and Chinese pages share the **same** file here; do not duplicate
  per locale. Use a `-en` / `-zh` suffix only when the screenshot itself is
  localized.

See `AUTHORING.md` §7.2 for the full asset convention.
