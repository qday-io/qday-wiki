# Roadmap

QDay is built in stages: EVM Layer 2 with quantum-resistant settlement, a global payment network around USD8, then native post-quantum accounts on L2. Dates can shift; treat the tables as the current public plan.

- **[QDAY PQC Roadmap](pqc-roadmap)** — post-quantum cryptography: L1-assisted rollups, then native PQC accounts
- **[QDAY Payment Roadmap](payment-roadmap)** — USD8, payment gateway, merchant rails, and agent payments
