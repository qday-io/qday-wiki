# Official contract addresses

Always verify you're interacting with these addresses — click to open the explorer, or copy. Never
migrate through an untrusted link.

## Migration (QDay → QDay2)

| Contract | Chain | Purpose |
|---|---|---|
| MigrationLockbox | QDay | Lock assets (one-way) |
| MigrationDistributor | QDay2 | Allocate 1:1 from the pre-funded pool |
| MigrationClaim | QDay2 | End-of-window backstop claim |

:::info[Addresses at launch]
The deployed migration contract addresses will be listed here and shown on the official portal for
anti-phishing verification.
:::
