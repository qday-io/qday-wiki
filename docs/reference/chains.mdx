# Chain parameters

The single source of truth for connecting to QDay and QDay2. Add either network to your wallet with
one click, or copy the values below.

| | QDay (source) | QDay2 (destination) |

Current **testnet** values — mainnet published at launch. Always verify against this page and the
[official contract addresses](contracts).
:::

## Manual setup

```json title="QDay2 network config"
{
  "chainId": "0xABE5",
  "chainName": "QDay2",
  "rpcUrls": ["https://rpc-test.qday.io"],
  "blockExplorerUrls": ["https://explorer-test.qday.io"],
  "nativeCurrency": { "name": "QDAY", "symbol": "QDAY", "decimals": 18 }
}
```
