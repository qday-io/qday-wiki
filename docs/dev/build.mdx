# Build a dApp on QDay

QDay is EVM-compatible, so any Ethereum stack works. Below: define the chain, connect a wallet, and
read/write a contract.

## 1. Define the chain

<Tabs groupId="lib">
<TabItem value="viem" label="viem / wagmi">

```ts title="chains.ts"
import { defineChain } from 'viem';

export const qday2 = defineChain({
  id: 44005,
  name: 'QDay2',
  nativeCurrency: { name: 'QDAY', symbol: 'QDAY', decimals: 18 },
  rpcUrls: { default: { http: ['https://rpc-test.qday.io'] } },
  blockExplorers: { default: { name: 'QDay2', url: 'https://explorer-test.qday.io' } },
});
```

</TabItem>
<TabItem value="ethers" label="ethers">

```ts title="provider.ts"
import { JsonRpcProvider } from 'ethers';

export const provider = new JsonRpcProvider('https://rpc-test.qday.io', {
  chainId: 44005,
  name: 'QDay2',
});
```

</TabItem>
</Tabs>

## 2. Read a contract (token balance)

<Tabs groupId="lib">
<TabItem value="viem" label="viem">

```ts
import { createPublicClient, http, erc20Abi } from 'viem';
import { qday2 } from './chains';

const client = createPublicClient({ chain: qday2, transport: http() });

const balance = await client.readContract({
  address: '0x…token',
  abi: erc20Abi,
  functionName: 'balanceOf',
  args: ['0x…user'],
});
```

</TabItem>
<TabItem value="ethers" label="ethers">

```ts
import { Contract } from 'ethers';
import { provider } from './provider';

const erc20 = new Contract('0x…token', ['function balanceOf(address) view returns (uint256)'], provider);
const balance = await erc20.balanceOf('0x…user');
```

</TabItem>
</Tabs>

## 3. Write a contract (send a tx)

```ts title="wagmi writeContract"
import { useWriteContract } from 'wagmi';

const { writeContractAsync } = useWriteContract();

await writeContractAsync({
  chainId: 44005,
  address: '0x…contract',
  abi,
  functionName: 'doSomething',
  args: [/* … */],
});
```
