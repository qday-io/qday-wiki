# QDay

**QDay** 是建構於 Abelian 之上、量子安全且相容於 EVM 的 Layer 2。**QDay Aevum** 是升級後的網路——整個生態系正在遷移至此鏈升級版本。本 wiki 涵蓋兩者：既有的 QDay 指南，以及 QDay Aevum 升級與遷移方式。

## 如何區分

| | QDAY V1（Origin） | QDAY V2（Aevum） |
|---|---|---|
| 狀態 | 已上線 | 測試網已上線；主網即將推出 |
| 主網鏈 ID | `44001` | `44002`（即將推出） |
| 測試網鏈 ID | `44003` | `44005` |
| 適用對象 | 現有使用者與指南 | 新功能 + 遷移目標 |

**QDay Aevum 主網即將推出** 
一切皆相容於 EVM——MetaMask、Solidity、wagmi/viem 在兩者上都能運作。
