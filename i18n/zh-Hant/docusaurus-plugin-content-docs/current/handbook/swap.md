# QDay Swap 用戶指引

QDay Swap 是基於 QDay 區塊鏈的去中心化交易平台，讓您可以快速兌換各種代幣，並通過提供流動性賺取收益。

:::tip[準備工作]
使用前，請確保您已安裝並設定好 [MetaMask 錢包](/guide/handbook/metamask) 並 [新增 QDAY 網路](/guide/handbook/metamask#新增-qday-網路到-metamask)。
:::

## 1. 代幣兌換 (Swap)

QDay Swap 支援在 **WABEL**、**QDAY**、**USD8** 三種代幣之間進行即時互換。

**操作步驟：**
1. 訪問 [QDay Swap](https://portal.qday.io/zh-HK/qday-swap) 並連接您的 MetaMask 錢包（請確保已切換至 QDAY 網路）。
2. 在「兌換」介面選擇您要支付與接收的代幣。
3. 輸入數量，系統會自動計算匯率與預估收到的代幣。
4. 點擊「兌換」並在錢包中確認授權及交易即可完成。

![QDAY Swap 兌換](/qday/swap/swap.png)

## 2. 流動性池 (Liquidity Pools)

通過向流動性池提供代幣，您可以成為流動性提供者 (LP) 並賺取交易手續費收益。「流動性池」頁面包含「池統計」與「添加流動性」兩個標籤頁：

### 池統計
在這裡可以查看不同流動性池的數據。您可以透過下拉選單在以下三個方案之間切換查看：
- **QDAY / USD8**
- **QDAY / WABEL**
- **WABEL / USD8**

![池統計](/qday/swap/liquidity_pool.png)

### 添加流動性
**操作步驟：**
1. 切換至「添加流動性」標籤頁，在 **WABEL**、**QDAY**、**USD8** 三種代幣之間選擇您要提供流動性的代幣對。
2. 選擇適合的手續費等級（預設推薦為 0.30% 或 0.05%），然後點擊「繼續」按鈕。
3. 在接下來的介面中（如下圖所示，以 QDAY/USD8 為例），輸入想要添加的代幣數量，系統會根據當前匯率自動計算另一種代幣的所需數量。
4. 點擊底部的「添加流動性」按鈕，並在錢包中確認授權及交易，完成後您將獲得相應的 LP 份額。

![添加流動性](/qday/swap/add_liquidity.png)

## 3. 管理倉位與交易記錄

- **我的倉位**：在「流動性池」頁面中點擊「我的倉位」，即可查看您目前提供的流動性詳情，並隨時進行「移除流動性」操作。
- **交易記錄**：點擊右上角您的錢包地址，選擇「交易記錄」即可查看所有兌換與流動性操作歷史。

:::danger[安全警告]
請務必通過官方連結 (https://portal.qday.io/zh-HK/qday-swap) 訪問 QDay Swap，謹防釣魚網站。進行大額交易前，建議先以小額測試流程。
:::
