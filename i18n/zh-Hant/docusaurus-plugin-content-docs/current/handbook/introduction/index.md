# 簡介

## 甚麼是 QDay {/* #what-is-qday */}

QDay 是建構於 Abelian 之上、兼容 EVM 的 Layer-2 網絡。Abelian 是一條抗量子的 Layer-1 區塊鏈，其主網已運行多年。Abelian 以格密碼學保護自身安全——美國國家標準與技術研究院（NIST）認可這類加密技術能夠抵禦量子電腦的攻擊。由於 QDay 的交易會以 Rollup 方式提交至 Abelian，QDay 因而繼承了這種抗量子安全，同時仍與以太坊的智能合約語言及開發者工具完全兼容。

QDay 分三個階段建構：

1. **抗量子結算。** 最先建立，採用零知識 Rollup 技術。
2. **全球支付網絡。** 圍繞 QDay 自家的穩定幣 USD8 建構，為日常商業活動以及由 AI 代理發起的支付而設計。
3. **原生抗量子帳戶與錢包。** 直接引入 QDay 本身，讓用戶不再僅依賴 Rollup 層級的保護。

QDay 專為以下對象而建：

- 需要低成本、高吞吐量結算的支付處理商及商戶——從傳統店舖到由 AI 代理驅動的商業活動。
- 需要抗量子結算基礎設施的資產代幣化平台。
- 開發去中心化金融（DeFi）應用的開發者。
- 小型團隊及個人創業者——包括依靠 AI 代理經營大部分業務的「一人公司」。

QDay 旨在解決三個大多數區塊鏈在設計時並未顧及的問題：

- 鏈上資產長期暴露於未來量子電腦的威脅之下。
- 缺乏為以機器速度進行交易的 AI 代理而設計的支付通道。
- 在許多通用型鏈上，成本與延遲令日常支付及微支付難以實行。

## 願景 {/* #vision */}

QDay 的長期目標，是成為一個涵蓋支付、去中心化金融、商業及 AI 原生服務的單一統一平台——全部由抗量子密碼學保護，並以 QDay 自家的穩定幣 USD8 作為價值在生態系統中流動的主要方式。

## 為甚麼選擇 QDay {/* #why-qday */}

QDay 的設計回應了三個同時發生的轉變。AI 代理正由被動工具轉變為能代表個人規劃、決策及付款的自主經濟參與者——這需要具備可編程支出規則及可驗證身份的支付通道，而大多數金融系統和區塊鏈在設計時並未顧及這一點。穩定幣已成為在鏈上轉移美元的主流方式，每年結算金額達數萬億美元。與此同時，新一代「代理支付」（agentic payment）協議正在興起——讓 AI 代理能直接為 API 呼叫及服務付款，無需訂閱或人手核准。

QDay 正建構於這三個轉變的交匯點：一條兼容 EVM、由後量子密碼學保護結算的鏈，擁有原生穩定幣 USD8，以及專為 AI 代理和人類而設計的支付基礎設施。QDay 將速度與低成本視為起點而非差異化優勢——抗量子結算與原生 AI 代理支付才是它的與別不同之處。
