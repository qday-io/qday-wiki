# 簡介

## 什麼是 QDay

QDay 是建構於 Abelian 之上、相容 EVM 的 Layer-2 網路。Abelian 是一條抗量子的 Layer-1 區塊鏈，其主網已穩定運行多年。Abelian 以格密碼學（lattice-based cryptography）保護自身安全——這類加密技術已獲美國國家標準暨技術研究院（NIST）認可，能夠抵禦量子電腦的攻擊。由於 QDay 的交易會以 rollup 的方式結算至 Abelian，QDay 因此繼承了這種抗量子的安全性，同時仍與 Ethereum 的智慧合約語言及開發者工具完全相容。

QDay 的建構分為三個階段：

1. **抗量子結算。** 最先建立，採用零知識 rollup 技術。
2. **全球支付網路。** 圍繞 QDay 自有的穩定幣 USD8 建構，為日常商務以及由 AI 代理發起的支付而設計。
3. **原生抗量子帳戶與錢包。** 直接導入 QDay 本身，使用者不再僅依賴 rollup 層級的保護。

QDay 專為以下對象打造：

- 需要低成本、高吞吐量結算的支付處理商與商家——從傳統店面到由代理驅動的商務。
- 需要抗量子結算基礎設施的資產代幣化平台。
- 建構去中心化金融（DeFi）應用的開發者。
- 小型團隊與獨立創業者——包括依靠 AI 代理經營大部分業務的「一人公司」。

QDay 的存在是為了解決三個多數區塊鏈在設計之初並未考慮的問題：

- 鏈上資產長期暴露於未來量子電腦的威脅之下。
- 缺乏為 AI 代理以機器速度進行交易而設計的支付軌道。
- 在許多通用型鏈上，成本與延遲使日常支付與微支付難以實現。

## 願景

QDay 的長期目標是成為一個單一、統一的平台，涵蓋支付、去中心化金融、商務與 AI 原生服務——全部由抗量子密碼學保護，並以 QDay 自有的穩定幣 USD8 作為價值在生態系中流動的主要方式。

## 為什麼選擇 QDay

QDay 的設計回應了三個同時發生的轉變。AI 代理正從被動工具轉變為能代表個人規劃、決策與付款的自主經濟行為者——這需要具備可程式化支出規則與可驗證身分的支付軌道，而多數金融系統與區塊鏈在設計之初並未考慮這一點。穩定幣已成為在鏈上轉移美元的主流方式，每年結算金額達數兆美元。同時，新一代「代理支付」（agentic payment）協定正在興起——讓 AI 代理能直接為 API 呼叫與服務付款，無需訂閱或人工核准。

QDay 正建構於這三個轉變的交會點：一條相容 EVM 的鏈，其結算由後量子密碼學保護，並擁有原生穩定幣 USD8，以及專為 AI 代理與人類設計的支付基礎設施。QDay 將速度與低成本視為起點而非差異化優勢——抗量子結算與原生代理支付才是其與眾不同之處。
