# 在 QDAY 上賺取收益

在 QDay 與 Abelian 社群中賺取 QDAY 的方式：空投、流動性挖礦、質押、生態系激勵、推薦計畫與大使計畫。請務必使用 **官方** QDay 連結。QDay 絕不會主動私訊你，也不會向你索取助記詞。

## 空投

QDay 空投用於獎勵 **活躍的 QDay 與 Abelian 社群成員**。資格與數量由各活動個別設定（例如 Discord / X 的活躍度、測試網使用情況，或持有並使用 QDay 產品）。QDAY 總供應量的 10% 保留給社群與生態系，其中包含空投——請參閱 [代幣經濟](/guide/handbook/tokenomics)。

**如何領取**

1. 關注官方頻道的公告：[Discord](https://discord.gg/Rrb33mC3Kc)、[X (@QDayOfficial)](https://x.com/QDayOfficial) 以及 [QDay Portal](https://portal.qday.io)。
2. 活動開放時，前往這些頻道所連結的 **官方空投入口**（由 [portal.qday.io](https://portal.qday.io) 進入——切勿透過陌生私訊或仿冒網址進入）。
3. 連接你在 QDay / Abelian 上使用的同一個錢包（請參閱 [MetaMask](/guide/handbook/user-guide/metamask) 或 [Abelian 行動錢包](/guide/handbook/user-guide/abelian-mobile-wallet)）。
4. 檢查資格、閱讀條款並領取。在錢包中確認交易。Gas 以 QDAY 支付。

:::danger[釣魚詐騙]
只從官方 QDay 帳號發布的連結領取。若某個假「空投」網站要求你輸入助記詞、私鑰，或要求對未知代幣「授權無限額度」，那就是詐騙。
:::

## 流動性挖礦

為 QDay 的交易協定提供流動性，即可賺取交易手續費分潤（以及該池提供的額外挖礦獎勵）。這是你在賺取收益的同時，協助 QDay 市場維持流動性的方式。

**Q-Swap 上的核心交易對：** QDAY/USD8、QDAY/WABEL 與 WABEL/USD8。

**如何參與**

1. 將 QDay 新增至你的錢包，並持有交易對中的兩種代幣（另外準備少量 QDAY 作為 Gas）。
2. 開啟 [QDay Swap](https://portal.qday.io/en/qday-swap) → **Liquidity Pools（流動性池）**。
3. 在 **Pool Statistics（池統計）** 中比較各池，然後 **Add Liquidity（新增流動性）**：選擇交易對與手續費等級（通常預設為 0.30%），並存入兩種代幣。
4. 在 MetaMask 中確認。你將收到 LP 份額。手續費會累積到池中；你可以隨時從 **My Positions（我的部位）** 移除流動性。

完整截圖與步驟：[Swap 使用指南](/guide/handbook/user-guide/swap#流動性池)。

:::tip[無常損失]
LP 收益取決於交易量與價格波動。請先從小額開始，並在存入大額部位前先閱讀池統計資料。
:::

## 質押

透過 QDay 的質押協定進行質押，以賺取協定獎勵。QDAY 供應量的 **35%** 保留作為質押獎勵；鎖倉時間越長，可獲得的份額越大。

兩種產品共用同一個 [質押入口](https://portal.qday.io/en/staking)：

| 協定 | 質押的資產 | 獲得的獎勵 | 指南 |
|---|---|---|---|
| **QDAY 質押** | QDAY / WQDAY | QDAY 獎勵 | [QDAY 質押](/guide/handbook/user-guide/qday-staking) |
| **ABEL 質押** | WABEL（跨鏈至 QDay 的 ABEL） | QDAY 獎勵 | [ABEL 質押](/guide/handbook/user-guide/abel-staking) |

**如何參與**

1. 在 MetaMask 中 [新增 QDay 網路](/guide/start/add-network)。
2. 持有你想質押的資產（若使用 ABEL 質押，請先將 ABEL 跨鏈為 WABEL）。
3. 開啟質押入口，連接錢包，選擇代幣、數量與鎖倉期間（最長 1,460 天 / 4 年）。
4. 確認 **Stake（質押）**。獎勵每日累積，可獨立於鎖倉期間隨時領取；本金的解除質押需等待鎖倉期結束。

鎖倉中的代幣無法提前提領。簽署前請確認你位於 `portal.qday.io`。

## 生態系激勵

QDay 基金會支持 **建設並推廣** 生態系的人——文件、工具、整合、教育、活動與開源工作——而不僅是投入質押或 LP 的資金。

常見的貢獻類型：

- 在 QDay 上建構 dApp、整合或開發者工具
- 撰寫指南、翻譯或教學
- 舉辦協助新使用者的聚會、工作坊或線上活動
- 回報問題並改善官方產品

**如何參與**

1. 公開進行你的工作（GitHub、Discord、X），以便驗證。
2. 關注 [社群](/guide/handbook/community) 頻道，掌握補助 / 賞金的開放時段。
3. 在開放期間申請或提交提案，附上簡短說明、工作成果連結，以及你所需要的支援。
4. 若獲核准，基金會（或隨治理推出後的 DAO）將依該計畫的條款發放獎勵。

面向建設者的計畫也列於 [在 QDay 上建構](/guide/handbook/build-on-qday)。

## 推薦計畫

透過將 **新使用者** 帶入網路來壯大 QDay。當活動進行時，你可以分享你的官方推薦連結；符合資格的註冊或首次操作（例如新增網路、一次兌換或一次質押）可為你帶來獎勵。

**如何參與**

1. 等待官方推薦活動（Portal、Discord 或 X）。非官方的「推薦機器人」並非 QDay 的計畫。
2. 在 [QDay Portal](https://portal.qday.io) 開啟活動頁面，並連接錢包以產生 **你的** 推薦連結。
3. 將該連結分享給 QDay 的新使用者。他們需完成活動所要求的事項（連接錢包、測試網交易等）。
4. 在同一個官方頁面上追蹤邀請與領取情況。獎勵依該活動的規則發放。

:::warning[請勿購買假使用者]
只有真實的新使用者才算數。付費購買的刷量帳號，以及任何非 `qday.io` / `qday.info` 的頁面，都不會獲得獎勵，且可能導致你的錢包被排除。
:::

## 大使計畫

QDay 大使是長期 **代表並推廣 QDay** 的社群成員——經營在地或語言社群、持續產出內容、舉辦活動與協助新手上手——並可因這些工作獲得基金會獎勵。

**大使通常會做的事**

- 主持或管理某個地區 / 語言社群
- 定期發布準確的說明內容（討論串、影片、工作坊）
- 在不經手任何人金鑰的前提下，協助新手加入網路
- 透過官方 Discord 將回饋傳達給核心團隊

**如何申請**

1. 先在官方 [社群](/guide/handbook/community) 頻道保持活躍並提供建設性貢獻。
2. 申請開放時，使用 QDay 公告的表單或 Discord 流程——而非私訊中的陌生人。
3. 說明你的受眾、語言、過去的貢獻，以及你將如何推廣 QDay。
4. 若獲錄取，請遵循大使簡報（品牌、可做出的宣稱，以及獎勵的發放方式）。

:::info[僅限官方]
大使頭銜、工具包與款項皆由 QDay 提供。沒有人需要付費才能「成為大使」。
:::
