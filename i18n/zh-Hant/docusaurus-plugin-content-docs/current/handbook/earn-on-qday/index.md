# 在 QDAY 上賺取收益

在 QDay 及 Abelian 社群中賺取 QDAY 的方式：空投、流動性挖礦、生態系統激勵、推薦計劃及大使計劃。請務必使用**官方** QDay 連結。QDay 絕不會主動私訊你，也不會向你索取助記詞。

## 空投 {/* #airdrop */}

QDay 空投獎勵**活躍的 QDay 及 Abelian 社群成員**。資格及數量由每個活動自行設定（例如 Telegram / X 上的活躍度、測試網使用情況，或持有及使用 QDay 產品）。QDAY 總供應量的 10% 預留給社群與生態系統，當中包括空投——請參閱[代幣經濟](/guide/handbook/tokenomics)。

**如何領取**

1. 留意官方渠道的公告：[Telegram](https://web.telegram.org/k/#@qday_official_group)、[X (@QDayOfficial)](https://x.com/QDayOfficial) 及 [QDay Portal](https://portal.qday.io)。
2. 活動開始時，前往這些渠道所連結的**官方空投入口**（經 [portal.qday.io](https://portal.qday.io) 進入——切勿透過陌生私訊或仿冒網址進入）。
3. 連接你在 QDay / Abelian 上使用的同一個錢包（請參閱 [MetaMask](/guide/handbook/user-guide/metamask) 或 [Abelian 手機錢包](/guide/handbook/user-guide/abelian-mobile-wallet)）。
4. 檢查資格、細閱條款，然後領取。在錢包中確認交易。Gas 以 QDAY 支付。

:::danger[釣魚詐騙]
只從官方 QDay 帳戶發佈的連結領取。若有假冒的「空投」網站要求你輸入助記詞、私鑰，或對不明代幣「授權無限額度」，那就是詐騙。
:::

## 流動性挖礦 {/* #liquidity-mining */}

為 QDay 的交易協議提供流動性，即可賺取部分交易手續費（以及該流動性池提供的任何額外挖礦獎勵）。這是你在賺取收益的同時，協助 QDay 市場保持流動性的方式。

**QDay Swap 上的核心交易對：** QDAY/USD8、QDAY/WABEL 及 WABEL/USD8。

**如何參與**

1. QDay Swap 運行於 **QDay Origin 主網（鏈 ID 44001）**——請將該網絡新增至你的錢包（參數見 [QDay Swap](/guide/handbook/user-guide/swap) 指南），並持有交易對中的兩種代幣（另加少量 QDAY 作 Gas）。
2. 開啟 [QDay Swap](https://portal.qday.io/en/qday-swap) → **Liquidity Pools**（流動性池）。
3. 在 **Pool Statistics**（池統計）中比較各個流動性池，然後點擊 **Add Liquidity**（新增流動性）：選擇交易對及手續費等級（通常預設為 0.30%），並存入兩種代幣。
4. 在 MetaMask 中確認。你會收到 LP 份額。手續費會累積在流動性池中；你可隨時在 **My Positions**（我的倉位）移除流動性。

完整截圖及步驟：[QDay Swap](/guide/handbook/user-guide/swap#liquidity-pools) 使用指南。

:::tip[無常損失]
LP 回報取決於交易量及價格變動。請先以小額開始，並在存入大額倉位前先查看流動性池的統計數據。
:::

## 生態系統激勵 {/* #ecosystem-incentives */}

QDay 基金會支持**建設及推廣**生態系統的人——文件、工具、整合、教育、活動及開源工作——而不僅是投入質押或 LP 的資金。

常見的貢獻包括：

- 在 QDay 上開發 dApp、整合或開發者工具
- 撰寫指南、翻譯或教學
- 舉辦協助新用戶的聚會、工作坊或網上活動
- 回報問題及改善官方產品

**如何參與**

1. 公開進行你的工作（GitHub、Telegram、X），以便核實。
2. 關注[社群](/guide/handbook/community)渠道，留意資助 / 賞金的開放時段。
3. 在申請期開放時提交申請或提案，附上簡短說明、工作成果連結，以及你所需要的支援。
4. 若獲批准，基金會（或在治理逐步推出後由 DAO）會按該計劃的條款發放獎勵。

面向開發者的計劃亦列於[在 QDay 上開發](/guide/handbook/build-on-qday)。

## 推薦 {/* #referral */}

透過為網絡帶來**新用戶**來壯大 QDay。活動進行期間，你可分享你的官方推薦連結；合資格的註冊或首次操作（例如新增網絡或進行一次兌換）可為你賺取獎勵。

**如何參與**

1. 等待官方推薦活動（Portal、Telegram 或 X）。非官方的「推薦機械人」並非 QDay 的計劃。
2. 在 [QDay Portal](https://portal.qday.io) 開啟活動頁面並連接你的錢包，以產生**你的**推薦連結。
3. 將該連結分享給初次接觸 QDay 的人。他們需完成活動所要求的事項（連接錢包、測試網交易等）。
4. 在同一官方頁面追蹤邀請及領取情況。獎勵按該活動的規則發放。

:::warning[切勿購買假用戶]
只有真實的新用戶才會計算在內。付費購買的刷量帳戶，以及任何並非 `qday.io` / `qday.info` 的頁面，都不會獲得獎勵，並可能導致你的錢包被排除。
:::

## 大使 {/* #ambassador */}

QDay 大使是較長期**代表及推廣 QDay** 的社群成員——經營地區或語言社群、持續產出內容、舉辦活動及協助新用戶上手——並可因這些工作獲得基金會獎勵。

**大使通常會做的事**

- 主持或管理某個地區 / 語言社群
- 定期發佈準確的說明內容（帖子串、影片、工作坊）
- 在不經手任何人密鑰的前提下，協助新用戶加入網絡
- 透過官方渠道向核心團隊轉達回饋

**如何申請**

1. 先在官方[社群](/guide/handbook/community)渠道保持活躍並作出建設性貢獻。
2. 申請開放時，使用 QDay 公佈的表格或流程——而非私訊中的陌生人。
3. 說明你的受眾、語言、過往貢獻，以及你將如何推廣 QDay。
4. 若獲接納，請遵從大使簡介（品牌、你可作出的聲明，以及獎勵的發放方式）。

:::info[僅限官方]
大使名銜、資料套件及款項均由 QDay 提供。沒有人需要付費才能「成為大使」。
:::
