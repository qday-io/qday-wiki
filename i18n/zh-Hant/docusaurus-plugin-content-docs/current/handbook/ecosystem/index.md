# 生態系

## 概覽

QDay 的生態系分層建構：一個將 QDay 連接至 Abelian 以取得安全性與結算的核心協定、一組 DeFi 與跨鏈應用，以及一個圍繞 QDay 原生穩定幣 USD8 建構的 Agent 與支付層。

## DApp

QDay 的生態系應用包括：

- **ABEL 質押** — 在 QDay 上質押 ABEL，賺取質押與空投獎勵。
- **QDay Bridge** — 在 QDay 與其他 EVM 相容鏈之間轉移 ERC20、TRC20 與 QRC20 代幣。
- **QDay 質押** — 質押 QDAY 以支持網路並賺取獎勵。
- **Q-Swap** — QDay 的去中心化交易所，用於兌換代幣。
- [佔位] 預測市場規劃中。
- [佔位] 預言機服務規劃中。
- [佔位] 鏈上身分產品規劃中。

## DeFi

這些應用共同構成 QDay 的 DeFi 層：Q-Swap 負責代幣兌換，而 QDAY 與 ABEL 皆可進行質押。設計初衷是讓 QDay 的原生穩定幣 USD8 作為所有這些應用的主要抵押與結算資產，使 QDay 上的 DeFi 活動不受原生代幣價格波動的影響。

## AI 生態系

QDay 上的 AI Agent 擁有自己的錢包、註冊可驗證的鏈上身分，並直接以 USD8 支付服務費用——單次 API 呼叫即可即時付款，無需訂閱，也無需人工逐筆核准交易。

## Abelian 合作夥伴關係

Abelian 是 QDay 底層的 Layer 1 區塊鏈。它已在主網運行多年，採用工作量證明共識與基於格的密碼學——這套密碼學早於 QDay 並構成 QDay 自身抗量子設計的基礎。Abelian 提供 QDay 交易最終錨定的結算層、QDay 安全功能背後的抗量子簽章，以及 QDay 自身抗量子帳戶所依據的帳戶衍生標準。
