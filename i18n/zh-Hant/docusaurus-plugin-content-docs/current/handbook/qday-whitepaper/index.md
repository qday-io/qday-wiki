**摘要：** QDay 代表區塊鏈基礎設施的突破性進展，提供全球首個抗量子、EVM 兼容的網絡，專為保護數碼資產及推動新興的代理經濟而設計。

隨着自動化機器流量超越人類的網絡活動，加上量子硬件的進展速度超出以往預期，傳統區塊鏈基礎設施正面臨關乎存亡的密碼學及營運瓶頸。

QDay 以單一統一架構同時解決這兩項挑戰。QDay 建基於連接 AggLayer 的模組化 Polygon CDK 技術棧，提供亞秒級交易執行、低於一仙的手續費、高 TPS 吞吐量、透過 paymaster 引擎實現的 Gas 抽象、原生 ERC-4337 智能合約錢包、ERC-8004 鏈上代理身份，以及以原生、法幣支持的穩定幣計價的 x402 小額支付原語（代理及支付功能將隨 QDay 主網於 2027 年第一季推出）。長期的狀態結算及最終確定性錨定於 Abelian Layer 1 上的格密碼後量子密碼學，並輔以漸進式帳戶遷移路徑，逐步過渡至原生 ML-DSA-65 後量子簽名。

QDay 採取全面的生態系統策略，涵蓋核心 DeFi 應用、跨鏈橋及強化的支付功能，為區塊鏈環境打造完整的抗量子解決方案。平台的代幣經濟模型確保長期可持續發展，並激勵廣泛的網絡參與。

本文為 QDay 訂立全面的技術、經濟、密碼學及營運規範。

## 1. 引言 {/* #1-introduction */}

在數碼金融及分散式系統不斷演變的過程中，對安全性、擴展性、互操作性及實際可用性的不懈追求至關重要。全球數碼生態系統目前正同時經歷兩項結構性轉變，重新定義了底層區塊鏈基礎設施的要求：

- **轉向機器主導：** 根據 Cloudflare 的數據，由自主 AI 代理、機械人及後台微服務驅動的自動化流量，於 2026 年 6 月史上首次正式超越互聯網上的人類流量，佔全球網絡請求總量的 57.4%。其中代理式 AI 流量（即自主軟件代表委託人執行現實世界的金融及 API 操作）按年激增 7,851%。
- **量子威脅時間表加快：** 與此同時，實際的量子硬件進展大幅縮短了破解傳統公鑰密碼學的預計時間。Google Quantum AI、以太坊基金會與 Stanford 於 2026 年 3 月聯合發表的一篇里程碑論文，將破解 256 位元橢圓曲線密碼學（ECDSA）所需的物理量子位元數目估算降低了 40 倍，由 2,000 萬個物理量子位元減至少於 500,000 個。

傳統區塊鏈基礎設施從來沒有被設計成能同時應對這兩項挑戰。為快速執行而打造的高吞吐量 EVM 鏈，幾乎完全依賴傳統 ECDSA 簽名，令帳戶餘額、智能合約狀態及交易記錄極易受到「先收集、後解密」（Harvest Now, Decrypt Later，HNDL）量子攻擊。相反，專門打造的後量子區塊鏈一直以來都是孤立運作，欠缺 EVM 兼容性、開發者工具、具流動性的穩定幣，以及自主機器所需的高頻結算原語。

QDay 正好解決這個根本性的脫節。QDay 作為建於抗量子、基於格密碼的 Abelian Layer 1 區塊鏈之上的 Layer 2，是一個專門的區塊鏈網絡，建立了量子安全代理支付層（Quantum-Safe Agent Payment Layer）。QDay 結合 100% EVM 兼容性、模組化 Polygon CDK Rollup 執行、具流動性的穩定幣結算、原生 Gas 抽象、具會話策略的智能合約錢包，以及 x402 HTTP 小額支付協議支援，並具備雙重後量子安全保護。

### 1.1. Layer 2 與抗量子基礎的協同效應 {/* #11-the-synergy-of-layer-2-and-quantum-resistant-foundations */}

將 Layer 2 Rollup 執行與後量子 Layer 1 基礎結合的架構，建立了前所未有的安全性及吞吐量表現。透過將狀態更新及執行轉移至鏈下，同時把有效性證明直接錨定於後量子 Abelian 區塊鏈，QDay 實現了三項獨特的技術協同效應：

- **繼承後量子最終確定性：** 在 QDay 執行環境內處理的每一筆交易，都會被打包成零知識有效性證明，在 DA 層上驗證，並將每個批次的狀態根提交至 Abelian Layer 1。一經提交，QDay 狀態的不可篡改性及最終確定性便受到格密碼保護，而無論是傳統還是量子計算的攻擊者，在數學上都無法破解。
- **高吞吐量執行：** 透過在專用的 Layer 2 環境內執行狀態轉換，QDay 消除了 Layer 1 工作量證明共識的計算開銷及延遲，實現低於 1 秒的交易確認延遲，以及可超過每秒 4,000 筆交易的吞吐能力。
- **低於一仙的結算成本：** 與直接在 L1 執行相比，於鏈下處理交易可將 Gas 成本降低多個數量級，令平均交易手續費降至一仙以下，使高頻 API 小額支付在經濟上變得可行。

### 1.2. 以 POS-over-POW 模型創新 {/* #12-innovating-with-a-pos-over-pow-model */}

QDay 在共識拓撲上開創先河，實施一個直接疊加於 Abelian 區塊鏈底層工作量證明（POW）基礎之上的權益證明（POS）執行及驗證模型。這種 POS-over-POW 設計是業界首創的結構，結合了兩種共識範式的互補優勢：

- **POW 信任根：** 底層的 Abelian Layer 1 依靠基於格密碼的 POW，提供極度安全、去中心化且無法偽造的錨點，即使面對具備量子能力的攻擊者，亦能抵禦 51% 狀態改寫攻擊。
- **POS 驗證效率：** QDay Layer 2 執行層採用 POS 驗證拓撲，排序器（sequencer）及證明者（prover）須質押 $QDAY 代幣作為經濟抵押品。這種 POS 結構能實現快速出塊提案、確定性的交易排序、能源效益及即時軟最終確定性，而無須消耗大量能源。

這項策略性融合確保 QDay 在結算層提供最高程度的密碼學安全性，同時提供現代企業應用及自主 AI 代理所需的能源效益、速度及擴展性。

<a id="sec-1-4"></a>
### 1.4. 前路：開創抗量子區塊鏈的未來 {/* #14-the-road-ahead-pioneering-the-future-of-quantum-resistant-blockchain */}

QDay 抗量子安全性的開發將分兩個主要階段進行，為 QDay 建立兩層量子保護，並在兩者之間加入一個新的中間階段，以新增代理支付功能。

#### 第 1 階段：具 EVM 兼容性的抗量子 Rollup（The Vault） {/* #phase-1-quantum-resistant-rollups-with-evm-compatibility-the-vault */}

在這個階段，QDay 將透過向 Abelian 區塊鏈進行 ZK Rollup，引入抗量子帳本，同時繼承以太坊虛擬機（EVM）的帳戶模型及智能合約功能，以維持 EVM 兼容性。這讓以太坊開發者可以順暢過渡，並能使用現有的以太坊工具及語言。憑藉這種 L1 輔助的抗量子 Rollup，QDay 將能抵禦以修改帳本數據（例如交易次序、金額及狀態結構）為目標的量子攻擊。此外，一旦偵測到任何攻擊，QDay 能以抗量子的方式暫停 Rollup 的執行，從而防止資金損失；換言之，Rollup 一經暫停，攻擊者便無法再推進，因為他們無法偽造由 Rollup 營運者產生的抗量子簽名。

#### 第 1.5 階段：代理支付網絡（The Rail） {/* #phase-15-agentic-payment-network-the-rail */}

在這個階段，QDay 將進一步過渡至連接 AggLayer 的模組化 Polygon CDK 架構，並擴展以下功能：快速的亞秒級結算、法幣支持的原生穩定幣整合、paymaster Gas 抽象、用於按請求計費 API 小額支付的 HTTP x402 支付標頭、具會話範圍消費上限、限時到期及合約白名單的 ERC-4337 智能合約錢包，以及 ERC-8004 鏈上代理身份。

#### 第 2 階段：原生抗量子帳戶及智能合約（The Shield） {/* #phase-2-native-quantum-resistant-accounts-and-smart-contracts-the-shield */}

在這個階段，QDay 將透過為現有帳戶加入新的抗量子密鑰，並啟用需要抗量子密鑰簽名的操作，實現抗量子帳戶。為此，QDay 的 EVM 實作將會更新，以支援輔助的後量子密碼學密鑰及算法。在這個抗量子帳戶模型之上，QDay 將支援兩類智能合約：傳統合約及抗量子合約。支援 EVM 智能合約的錢包仍可與傳統合約互動，而抗量子合約則只供支援 QDay 內置抗量子密鑰及算法的錢包使用。

上述兩項抗量子機制是正交的。前者是針對帳本數據量子攻擊的一層防禦，後者則是針對特定帳戶量子攻擊的一層防禦。結合這兩項機制，將為 QDay 提供全面的抗量子安全性。舉例來說，即使攻擊者成功取得某些帳戶的私鑰（透過入侵受害者的電腦或其他方式），仍可透過暫停 Rollup 執行、採取補救措施（例如凍結受影響帳戶），最後再恢復 Rollup 執行，以防止資金損失。請注意，所有這些行動都會基於 Rollup 營運者的共識進行，而該共識在設計上既去中心化亦抗量子。

<a id="sec-2-1"></a>
### 2.1. Abelian 的抗量子密碼學 {/* #21-quantum-resistant-cryptography-in-abelian */}

我們可以將 Abelian 視為 QDay 基礎設施的第 0 階段。Abelian 已在正式生產環境運作多年，採用源自容錯學習（Learning With Errors，LWE）及環上容錯學習（Ring-LWE）數學難題的格密碼原語。傳統公鑰密碼學（例如 RSA 或基於 secp256k1 曲線的 ECDSA）依賴整數分解或離散對數，而這些問題可由量子電腦上的 Shor 算法在多項式時間內解決；格密碼則依賴在高維格中尋找最短向量，這個問題無論對傳統還是量子硬件而言仍然難以解決。

Abelian 的密碼學原語與美國國家標準與技術研究院（NIST）後量子密碼學（PQC）標準化項目所定案的標準高度一致，特別是用於密鑰封裝的 FIPS 203（ML-KEM / Kyber）及用於數碼簽名的 FIPS 204（ML-DSA / Dilithium）。這為 QDay 的結算層提供毫不妥協的密碼學基礎。

<a id="sec-2-2"></a>
### 2.2. QDay 至 Abelian Rollup 的抗量子密碼學 {/* #22-quantum-resistant-cryptography-in-qday-to-abelian-rollups */}

這是 QDay 實施的第 1 階段。

#### 創新的 POS-over-POW 共識整合 {/* #innovative-pos-over-pow-consensus-integration */}

POS-over-POW 是一種創新的共識機制，結合權益證明與工作量證明兩者的優勢，打造更安全、更高效的區塊鏈網絡。這種混合方式借助 POW 久經考驗的安全性，同時引入 POS 的能源效益及擴展性。

在 POS-over-POW 系統中，底層區塊鏈以 POW 共識機制運作，而 POW 以穩健及安全見稱。POW 涉及礦工競相解決複雜的數學難題，藉此驗證交易並保障網絡安全。這個過程需要大量計算並消耗能源，但由於攻擊網絡需要龐大的算力，因此能提供高度安全性。

在這個 POW 基礎之上，再實施一個 POS 層。在 POS 中，驗證者會根據其持有並願意「質押」作為抵押品的代幣數量，被選出建立新區塊及驗證交易。與 POW 相比，這個過程的能源消耗低得多，因為它不涉及解決複雜難題，而是依靠經濟激勵確保驗證者誠實行事。

與純粹的 POS 系統相比，POS-over-POW 共識機制具備多項優勢：

1. **更強的安全性**
    - POW 基礎：透過計算難度提供強大的安全性，令攻擊代價高昂且困難重重。
    - 協同安全：結合 POW 與 POS 的優勢，提升整體網絡安全性。
2. **能源效益**
    - 降低能源消耗：與單靠 POW 相比，POS 層大幅降低能源使用量。
    - 優化資源運用：利用 POW 提供安全性、POS 負責驗證，在安全性與能源效益之間取得平衡。
3. **擴展性**
    - 提升吞吐量：POS 層能更有效地處理交易，提升擴展性。
    - 分層架構：支援模組化升級，讓擴展性得以持續改進。
4. **經濟激勵**
    - 平衡的激勵結構：同時獎勵礦工及驗證者，並透過 POS 激勵推動積極參與。
    - 持份者參與：涵蓋廣泛的參與者，提升去中心化程度及韌性。
5. **抵抗中心化**
    - 分散式安全：POW 層將安全性分散至眾多礦工，確保去中心化。
    - 減低中心化風險：由於同時需要計算資源及已質押的代幣，減低了純 POS 系統常見的中心化風險。

QDay 實施的 POS-over-POW 借助 Abelian 區塊鏈 POW 基礎的穩健安全性，同時引入 POS 層以提升擴展性及效率。

#### 抗量子 Rollup {/* #quantum-resistant-rollups */}

抗量子 Rollup 的目標，是確保即使有人能使用量子電腦，亦無法修改或偽造 QDay 的帳本數據。這意味着 QDay 區塊鏈能以抗量子的方式暫停 Rollup 的執行；換言之，Rollup 一經暫停，攻擊者便無法再推進，因為他們無法偽造由 Rollup 營運者產生的抗量子簽名。在暫停期間，受影響的帳戶可被凍結，攻擊者亦可被舉報予有關當局。補救措施完成後，Rollup 便可恢復執行。請注意，現有的 Layer 2 解決方案無法實施這種抗量子暫停機制，因為它們無法阻止量子攻擊者破解 Rollup 營運者的私鑰。

在 QDay 中實施抗量子 Rollup 相當直接。每個 Rollup 營運者都會使用一個 Abelian 區塊鏈帳戶來運行 Rollup。Rollup 數據由 Layer 1 內置的抗量子密鑰及算法簽署。除了利用現有的抗量子 Layer 1 之外，其餘的 Rollup 實作可以與任何其他 Layer 2 解決方案完全相同。具體而言，QDay 的 ZK Rollup 是為配合 Abelian 區塊鏈的特性而打造。我們將在下一節說明技術細節。

<a id="sec-4-1"></a>
### 4.1. ZK Rollup 簡介 {/* #41-introduction-to-zk-rollups */}

ZK Rollup（Zero-Knowledge Rollup，零知識 Rollup）是一種尖端的 Layer 2 擴容方案，旨在解決區塊鏈技術固有的局限，特別是在可擴展性及交易吞吐量方面。ZK Rollup 把多筆交易聚合成單一批次，再將該批次提交至 Layer 1 主鏈，從而大幅減輕主鏈的運算負荷及儲存需求。

ZK Rollup 的核心創新在於使用零知識證明。這類密碼學證明讓一方可以向另一方證明某個陳述為真，而無需透露該陳述的任何具體資訊。在 ZK Rollup 的情境下，這意味着交易的正確性可以被驗證，而無需公開底層的交易數據。這不但加強了私隱，亦確保驗證過程既安全又高效。

此外，ZK Rollup 為「可擴展性三難困境」提供了一個有力的解決方案。該困境指出，要同時實現去中心化、安全性及可擴展性並不容易。ZK Rollup 將交易處理轉移至 Layer 2，同時保留 Layer 1 的安全保障，在提升整體網絡效能的同時，不會犧牲安全性或去中心化，取得了平衡。

<a id="sec-4-2"></a>
### 4.2. QDay 採用 Polygon ZK Rollup 技術 {/* #42-qdays-adoption-of-polygon-zk-rollups-technology */}

QDay 整合 Polygon ZK Rollup 技術，是一項策略性舉措，旨在善用目前最先進、最可靠的 Layer 2 方案之一。Polygon ZK Rollup 建基於穩健的密碼學基礎，能高效處理大量交易，因此是 QDay 提升可擴展性及私隱這兩個目標的理想選擇。

Polygon 的 ZK Rollup 採用 zk-SNARK（Zero-Knowledge Succinct Non-Interactive Arguments of Knowledge，零知識簡潔非互動式知識論證），這是一種既簡潔又非互動式的零知識證明。換言之，證明的體積細小，而且可以快速驗證，證明者與驗證者之間無需來回通訊。這項特性對區塊鏈應用尤其有利，因為效率和速度至關重要。

實際運作上，QDay 將使用 Polygon ZK Rollup 在鏈下處理交易，從而減輕 Abelian 主鏈的負荷。交易會被打包成單一證明，在 DA 層上驗證；其後批次狀態根會提交至 Abelian 鏈進行最終確定。這種做法不但提升交易吞吐量，亦降低 Gas 手續費，令網絡對用戶而言更具成本效益。

此外，Polygon 的 ZK Rollup 設計上具備高度互通性，能與不同的區塊鏈生態系統無縫整合。這種靈活性對 QDay 至關重要，因為 QDay 的目標是打造一個可擴展、具適應力，並能隨區塊鏈生態系統需求而演進的 Layer 2 方案。

QDay 實作的一個獨特之處，是以 Abelian（一條類似比特幣的區塊鏈）作為其 ZK Rollup 的 Layer 1 基礎。這有別於較常見、以 EVM 兼容鏈作為 Layer 1 基礎的做法。因此，QDay 需要對標準的 Polygon ZK Rollup 框架作出大幅修改，以確保與 Abelian 的架構兼容。

Abelian 與比特幣相似，所採用的共識機制及交易模型與 EVM 兼容鏈不同。具體而言，Abelian 使用 UTXO（Unspent Transaction Output，未花費交易輸出）模型，而 EVM 兼容鏈一般使用基於帳戶的模型。這項根本差異意味着 ZK Rollup 的數據結構及證明產生機制必須重新設計，以配合 UTXO 模型。

此外，Abelian 的共識算法本身設計為抗量子，在第 1 階段必須整合至 Rollup 的驗證流程之中。這涉及調整證明提交及驗證協議，以確保它們符合 Abelian 的共識規則。雖然這些修改的具體細節相當複雜且技術性高，但整體目標是讓 Rollup 與 Abelian 主鏈之間無縫互動，同時保留兩層各自的安全性及效率優勢。

<a id="sec-4-3"></a>
### 4.3. 抗量子 Rollup 的優勢 {/* #43-benefits-of-quantum-resistant-rollups */}

抗量子 Rollup 的主要優勢，在於一旦相應的 Rollup 獲 Abelian 確認，帳本中的數據便能抵禦量子攻擊。即使攻擊者擁有量子電腦，亦無法對帳本數據發動 51% 攻擊。特別是，這種防護同樣適用於待處理數據，即已提交至 QDay 但尚未獲 Abelian 確認的數據。這項新功能讓 QDay 能以抗量子的方式暫停 Rollup 的執行；換言之，Rollup 一經暫停，攻擊者便無法再推進，因為他們無法偽造由 Rollup 營運者產生的抗量子簽名。請注意，這種暫停機制只在 Rollup 營運者端運行，本身不會影響 QDay 區塊鏈的運作。

由於這是現有 Layer 2 方案均未支援的新功能，我們將以一個具體例子說明其運作方式。假設以下事件按時間順序發生：

#### 抗量子緊急暫停情境示範 {/* #a-quantum-resistant-emergency-halt-scenario-walkthrough */}

1. 一名擁有量子電腦的攻擊者利用 QDay 上某個 DeFi dApp 的漏洞，捲走資金池內的所有資金（rug pull）。
2. 被盜資金被轉移至一個由攻擊者控制的 QDay 帳戶。
3. 一名用戶察覺到該 rug pull，並向 dApp 提供者報告事件。
4. dApp 提供者凍結該帳戶，並向 QDay DAO 報告事件。
5. QDay DAO 建立一項投票提案，要求暫停 Rollup 執行 12 小時。
6. 所有 DAO 成員須於 30 分鐘內就該提案投票。
7. 提案獲得通過，Rollup 的執行隨即暫停。由此刻起，攻擊者無法將資金轉出 QDay，因為 QDay Bridge 不會處理任何未經 Rollup 確認的交易。
8. dApp 提供者會收到通知，表示他們約有 12 小時採取必要行動保護用戶資金。如有需要，他們可以要求 QDay DAO 延長暫停期，以爭取更多時間。
9. dApp 提供者聯絡代幣發行方，要求凍結所有由攻擊者控制的地址。請注意，凍結操作本質上是在 QDay 上的一次智能合約調用，不受 Rollup 暫停影響。
10. 代幣發行方要求 dApp 提供者出示 rug pull 的確實證據。在本例中，dApp 提供者提交了證據，並通過代幣發行方的審查。
11. 代幣發行方凍結攻擊者的地址。
12. Rollup 執行在以下任一情況下恢復：(1) 12 小時後；或 (2) dApp 提供者通知 QDay DAO 所有必要行動已完成，可以恢復 Rollup 執行。在後一種情況下，QDay DAO 亦會就恢復 Rollup 執行的提案進行投票。
13. QDay 區塊鏈恢復正常運作。dApp 提供者聯絡警方或其他相關當局舉報該 rug pull，並會對攻擊者採取進一步法律行動。
14. 如需採取任何進一步行動，QDay DAO 會就相關提案進行投票。一般而言，這類行動應由警方或其他相關當局提出。

值得注意的是，上述例子假設攻擊者擁有量子電腦。即使如此，攻擊者仍無法將資金轉出 QDay，因為 Rollup 流程需要由 Rollup 營運者產生的抗量子簽名。這個例子說明，抗量子暫停機制能提升部署在 QDay 上所有 dApp 的整體安全性。

<a id="sec-4-4"></a>
### 4.4. 未來工作：PQZK Bridge {/* #44-future-work-pqzk-bridge */}

#### 甚麼是 PQZK Bridge？ {/* #what-is-pqzk-bridge */}

PQZK Bridge（Post-Quantum Zero-Knowledge Bridge，後量子零知識橋）是一種密碼學協議，旨在協助區塊鏈系統安全、高效地過渡至後量子安全標準。它結合零知識證明的原理與後量子密碼算法，建立一個能抵禦量子電腦能力的穩健框架。

零知識證明（ZKP）讓一方可以向另一方證明某個陳述為真，而無需透露該陳述的任何具體資訊。在區塊鏈的情境下，ZKP 能在保障私隱的同時驗證交易的正確性。另一方面，後量子密碼學（PQC）涉及能抵禦量子電腦攻擊的密碼算法。

PQZK Bridge 以後量子密碼原語來構建零知識證明，從而整合這兩項技術，確保即使面對擁有量子能力的對手，證明仍然安全。PQZK Bridge 作為中介層，協助在現有區塊鏈平台上部署 PQZK Rollup，提供一條通往量子安全的無縫升級路徑。

#### 以 PQZK Bridge 實作 QDay 的 Rollup {/* #implementing-qdays-rollups-with-pqzk-bridge */}

為實作 PQZK Rollup，QDay 將利用 PQZK Bridge，由傳統的 ZK Rollup 過渡至完全抗量子的方案。

第一步是將後量子密碼原語整合至 Rollup 框架之中。這些原語（例如格密碼或基於雜湊的簽名）將取代零知識證明中使用的傳統密碼算法。

QDay 將使用這些後量子原語構建 PQZK 證明。這些證明會保留零知識特性，確保交易驗證無需透露任何敏感資訊，同時能抵禦量子攻擊。

其後，Rollup 協議將作出修改以納入 PQZK 證明，包括調整證明的產生、提交及驗證流程，以處理新的後量子密碼構造。

這些已納入 PQZK 證明的經修改 Rollup 協議，將部署於 Abelian Layer 1 區塊鏈上。Abelian 的抗量子特性將與 PQZK Rollup 相輔相成，提供穩健的端到端抗量子方案。

最後，我們將進行全面測試，以確保 PQZK Rollup 運作正確且高效。優化工作將集中於盡量減少後量子密碼運算帶來的額外運算開銷，確保 Rollup 方案保持可擴展及高效能。

#### 將 PQZK Rollup 擴展至其他 EVM 兼容鏈 {/* #extending-pqzk-rollups-to-other-evm-compatible-chains */}

PQZK Rollup 的優勢並不限於 QDay 和 Abelian。PQZK Bridge 技術可以擴展至其他 EVM 兼容鏈，讓它們同樣實現量子安全。

PQZK Bridge 可以按 EVM 兼容鏈的特定架構及共識機制作出調整。這涉及修改跨鏈橋協議，以確保與以太坊虛擬機及其他相關技術兼容。

完成調整後，PQZK Bridge 便可用於在不同的 EVM 兼容鏈上部署 PQZK Rollup，讓這些鏈以抗量子的方式在鏈下處理交易，提升其可擴展性及安全性。

藉助 PQZK Bridge 的互通性功能，不同的區塊鏈生態系統可以無縫整合 PQZK Rollup。這有助建立一個更安全、更緊密互聯的區塊鏈格局，讓多條鏈都能受惠於抗量子的交易處理。

為推動 PQZK Rollup 的採用，我們將提供詳盡的文件、開發者工具及社群支援，確保區塊鏈開發者能輕鬆在各自的平台上實作及部署 PQZK Rollup，加快邁向量子安全區塊鏈技術的步伐。

總括而言，透過 PQZK Bridge 採用 PQZK Rollup，QDay 不但提升自身的安全性，亦有助增強整個區塊鏈生態系統抵禦量子威脅的能力。這種積極主動的做法確保在量子運算技術不斷演進的同時，區塊鏈系統依然安全、可擴展及高效。

<a id="sec-5"></a>
## 5. 第 2 階段：具備 EVM 兼容性的抗量子帳戶 {/* #5-phase-2-quantum-resistant-account-with-evm-compatibility */}

在第 2 階段，QDay 將引入抗量子帳戶與傳統帳戶，以及以下相應的概念：

- 抗量子錢包與傳統錢包；
- 抗量子合約與傳統合約；
- 抗量子 dApp 與傳統 dApp。

傳統帳戶的每組助記詞都可用來衍生相應的抗量子帳戶，以確保由傳統帳戶順暢過渡至抗量子帳戶。所有 QDay 用戶都可以使用同一組助記詞，同時存取抗量子帳戶及傳統帳戶。具體而言，所有 EVM 兼容錢包將繼續使用傳統帳戶，無需任何改動，亦不會察覺抗量子帳戶的存在；而抗量子錢包則會就同一組助記詞同時支援抗量子帳戶及傳統帳戶。QDay 將提供抗量子錢包的參考實作，並將相應的原始碼開源。

除助記詞外，抗量子帳戶與傳統帳戶完全獨立。這是刻意的設計，以確保新帳戶的後量子安全性。具體而言，第 2 階段將實現以下目標：

- 傳統帳戶可以如以往一樣使用，即由傳統錢包及傳統智能合約支援。
- 抗量子帳戶可以配合抗量子錢包使用。預計不會有傳統錢包支援抗量子帳戶。
- QDay 團隊提供的抗量子錢包參考實作將支援傳統帳戶。至於由其他方實作的抗量子錢包，是否支援傳統帳戶則屬可選。
- 抗量子合約將「不會」支援傳統帳戶。這是確保後量子安全性不會因混用非抗量子密碼原語而受損的關鍵。
- 抗量子合約將以兩種方式與傳統合約兼容：1) 抗量子合約可以包含非抗量子的傳統函數；2) 傳統錢包可以借助外部抗量子簽名產生器，調用抗量子函數。
- 部分抗量子 dApp 可能會同時實作抗量子及傳統協議，從而支援傳統帳戶。
- 抗量子帳戶可以透過抗量子錢包，與抗量子智能合約及 dApp 互動。若抗量子錢包針對相關情況支援後備機制，抗量子帳戶亦可能與傳統智能合約及 dApp 互動。
- 下表顯示抗量子物件能否與傳統物件互動或支援傳統物件。請注意，傳統物件肯定無法與抗量子物件互動，因此我們不列出反方向的對應表格。

| 物件 | 傳統帳戶 | 傳統錢包 | 傳統合約 | 傳統 dApp |
|---|---|---|---|---|
| **抗量子帳戶** | 可能後備至 | 不能被其使用 | 可能與其互動 | 可能與其互動 |
| **抗量子錢包** | 可能支援相同助記詞 |——| 可能支援 | 可能支援 |
| **抗量子合約** | 不兼容 | 不兼容 | 不兼容 | 不兼容 |
| **抗量子 dApp** | 可能支援 | 可能被其使用 | 可能支援 | 可能支援 |

總括而言，第 2 階段的目標是在不犧牲任何後量子安全特性的前提下，加入對抗量子物件的支援，同時與傳統物件保持最大程度的向後兼容。本節餘下部分將先描述 QDay 第 2 階段核心組件的整體設計，再闡述設計原則及取捨。

<a id="sec-5-1"></a>
### 5.1. 抗量子帳戶 {/* #51-quantum-resistant-account */}

QDay 的抗量子帳戶將採用與 Abelian 區塊鏈相同的後量子密碼原語。它與傳統帳戶由同一組助記詞開始，但自此之後便完全分道揚鑣。

由 BIP-39 助記詞衍生抗量子帳戶的流程，定義於 AIP-11（Abelian Improvement Proposal 11）。為方便讀者，我們在此簡述有關流程。

#### 第 1 步：由助記詞到 Entropy-Seed {/* #step-1-from-mnemonic-to-entropy-seed */}

AIP-11 採用與 BIP-39 相同的 entropy-seed 衍生流程。然而，AIP-11 要求 entropy-seed 長度為 256 位元，即對應 24 個助記詞。為此，若助記詞少於 24 個字，我們會以 "abandon"（BIP-39 詞表中的第一個字）補足至 24 個字；若助記詞多於 24 個字，則會截取為 24 個字。

#### 第 2 步：由 Entropy-Seed 到 Master-Seed {/* #step-2-from-entropy-seed-to-master-seed */}

其後，entropy-seed 會透過確定性的密鑰衍生函數，衍生出 512 位元的 master-seed。該密鑰衍生函數定義如下：

```
MasterSeed = PRF(EntropySeed, 'AccountMasterSeed')
```

其中 PRF 是一個以 KMAC256 作為底層雜湊函數的後量子密鑰衍生函數，定義如下：

```
PRF(key, input) := KMAC256(key, input, 512, 'ABELIANPRF')
```

#### 第 3 步：由 Master-Seed 到 Account-Root-Seeds {/* #step-3-from-master-seed-to-account-root-seeds */}

在 Abelian 中，每個帳戶由一組根種子組成，即 CoinSpKeyRootSeed、CoinSnKeyRootSeed、CoinDetectorRootKey 及 CoinVKRootSeed，統稱為 Account-Root-Seeds。所有根種子均為 512 位元長，透過以下密鑰衍生函數由 master-seed 衍生：

```
CoinSpKeyRootSeed   = PRF(MasterSeed, 'CoinSpendKeyRootSeed')
CoinSnKeyRootSeed   = PRF(MasterSeed, 'CoinSerialNumberKeyRootSeed')
CoinDetectorRootKey = PRF(MasterSeed, 'CoinDetectorRootKey')
CoinVKRootSeed      = PRF(Master-Seed, 'CoinValueKeyRootSeed')
```

請注意，此處的 PRF 函數與上一步所用的相同。

#### 第 4 步：由 Master-Seed 到 Public-Rands {/* #step-4-from-master-seed-to-public-rands */}

在 AIP-11 中，每組根種子可按不同的 public rand 值衍生多個地址。在 QDay 中，為符合現有分層確定性錢包（HDW）的慣例，我們將使用 AIP-11 定義的以下確定性函數，由 master-seed 及一個序號衍生 public rand。具體而言，public rand 的衍生方式如下：

```
PublicRand(index) = PRF(PublicRandRootSeed, index)
```

其中

```
PublicRandRootSeed = PRF(MasterSeed, 'PublicRandRootSeed')
```

#### 第 5 步：由 Account-Root-Seeds 及 Public-Rand 到地址及私鑰 {/* #step-5-from-account-root-seeds-and-public-rand-to-address-and-private-key */}

當 account-root-seeds 及 public-rand 均已衍生後，便可確定性地衍生相應的地址及私鑰。由於此流程不屬 AIP-11 的範圍，我們將採用 Abelian SDK v2 中實作的相同流程，以便與 Layer 1 鏈的生態系統保持更高的一致性。

<a id="sec-5-2"></a>
### 5.2. QDay 節點升級 {/* #52-upgrade-of-qday-nodes */}

要令抗量子帳戶有實際意義，區塊鏈首先必須支援原生代幣 $QDAY 在傳統帳戶與抗量子帳戶之間轉帳。具體而言，QDay 節點必須升級，以便能夠：1) 識別抗量子帳戶的新類型地址；2) 驗證抗量子帳戶產生的簽名；3) 支援原生代幣 $QDAY 在傳統帳戶與抗量子帳戶之間轉帳。然而，要滿足第三項要求並不簡單，因為我們需要保持向後兼容，讓傳統錢包在不認識新類型地址的情況下也能進行這類轉帳。

這裏的一個關鍵挑戰，是能否在不更改傳統錢包的情況下，支援原生代幣 $QDAY 在傳統帳戶與抗量子帳戶之間轉帳。為應對這項挑戰，我們將在 QDay 區塊鏈上開發一個智能合約，作為傳統帳戶與抗量子帳戶之間的橋樑。該智能合約本身屬傳統合約，可供傳統錢包使用。

1. 傳統帳戶調用該智能合約的 `Send` 函數，以抗量子帳戶作為收款人，並輸入原生代幣 $QDAY 的金額。
2. 智能合約驗證傳統帳戶的簽名及收款人地址。
3. 智能合約從傳統帳戶收取 $QDAY，並將其發送至抗量子帳戶。

在最後一步，智能合約會將 $QDAY 由其自身的傳統地址轉至收款人的抗量子地址。這是透過調用 QDay 節點實作的新原語函數 `legacy_to_quantum_resistant_transfer` 完成的。QDay 節點的 EVM 實作將會升級以支援此原語函數，以及處理反向流程的另一個原語函數 `quantum_resistant_to_legacy_transfer`。

雖然上述兩個原語函數的介面看似簡單，但其實作並不簡單，需要一整套同時涉及傳統算法及後量子算法的密碼運算。有關技術細節超出本白皮書的範圍，我們將在開源 QDay 節點的實作時詳細說明。

<a id="sec-5-3"></a>
### 5.3. 抗量子錢包 {/* #53-quantum-resistant-wallet */}

顯然，所有現有的 EVM 錢包都不會支援 QDay 定義的抗量子帳戶，因為它們本來就不打算支援任何後量子安全功能。因此，有必要實作一種新類型的錢包，以支援 QDay 的抗量子帳戶。我們將在 QDay 第 2 階段提供這類錢包的參考實作，並將程式碼向公眾開源，協助社群或任何其他方構建兼容的抗量子錢包。

如要建立或匯入抗量子帳戶，用戶將使用與傳統帳戶相同的助記詞。錢包會由助記詞衍生抗量子帳戶，並用它轉帳原生代幣 $QDAY，以及與抗量子智能合約及 dApp 互動。

如要將 $QDAY 由抗量子帳戶轉至傳統帳戶，抗量子錢包會直接向區塊鏈節點提交交易。這與在傳統錢包中由傳統帳戶轉帳 $QDAY 至抗量子帳戶的做法不同。正如上一節所述，第 2 階段升級後，QDay 節點將能直接處理這類交易，因此在這種情況下無需使用智能合約橋。

抗量子錢包的主要用途是與抗量子智能合約及 dApp 互動。要了解抗量子錢包如何與抗量子智能合約互動，我們需要先了解抗量子智能合約的設計及實作方式。因此，這部分將留待下一節詳細介紹抗量子智能合約時再作說明。

此外，若實作得宜，抗量子錢包亦可用於與傳統智能合約及 dApp 互動。在參考實作中，我們將提供後備機制以支援這類情況。具體而言，如要與傳統智能合約互動，錢包會使用相應的傳統地址調用該智能合約，而資產遷移則由錢包自動處理。例如，如要與一個將 $QDAY 兌換為本鏈日後推出的原生穩定幣的智能合約互動，錢包會在調用智能合約前將 $QDAY 轉至傳統地址，並在調用完成後將穩定幣轉至抗量子地址。

<a id="sec-5-4"></a>
### 5.4. 抗量子合約 {/* #54-quantum-resistant-contracts */}

在 QDay 第 2 階段，抗量子合約可以視為在傳統合約之上額外加入一層後量子簽名驗證。從調用者的角度看，抗量子合約與傳統合約基本上相同，唯一分別是調用者每次調用應屬抗量子的合約方法時，都需要額外提供一個抗量子簽名。該抗量子簽名透過合約方法的一個普通參數傳入，並由合約本身驗證。

以抗量子 ERC20 合約中的 transfer 方法為例。傳統 ERC20 方法簽名如下：

```solidity
function transfer(address to, uint256 value) external returns (bool);
```

該方法的抗量子版本如下：

```solidity
function pq_transfer(bytes pq_sig_data, address to, uint256 value) external returns (bool);
```

其中 `pq_sig_data` 是抗量子簽名。

根據 QDay 定義的慣例，函數名稱必須以 `pq_` 作為前綴，而簽名必須是第一個參數。這項慣例讓抗量子方法與傳統方法易於區分。更重要的是，憑藉這項慣例，QDay 節點可以自動驗證抗量子簽名，合約無需額外程式碼。具體而言，只要簽名數據按照 QDay 定義的標準方式產生，並作為第一個參數傳入名稱以 `pq_` 為前綴的函數，QDay 節點便會使用內置的抗量子簽名驗證機制驗證該簽名。

理論上，若能解決以下問題，同一機制亦可在任何 EVM 兼容鏈上的傳統合約中實作：

1. 抗量子簽名可由抗量子錢包，或符合 QDay 所定義標準的外部工具產生。
2. 抗量子簽名可在合約函數內使用常規 EVM 指令進行驗證。

第一個問題較易解決，但若使用傳統錢包配合外部工具，用戶體驗可能未如理想。第二個問題則可能相當棘手，因為在合約函數內以常規 EVM 指令實作抗量子密碼運算並不簡單。更甚的是，這些運算非常耗用資源，可能導致用戶需支付難以負擔的 Gas 手續費。

請注意，第二個問題在 QDay 中並不存在，因為抗量子簽名驗證是 QDay 的內置功能，運算在 QDay 節點的作業系統上以原生方式執行（即不經 EVM），因此運算成本不會以 Gas 手續費的形式轉嫁用戶。

<a id="sec-5-5"></a>
### 5.5. 抗量子 dApp {/* #55-quantum-resistant-dapps */}

由上文可見，智能合約必須升級才能支援抗量子簽名。為求順暢過渡，在第 1 階段部署的 dApp 可以保持其用戶介面不變。做法是先在 dApp 所用的智能合約中加入新的抗量子方法，同時所有現有的傳統方法必須保持不變，讓傳統錢包可以如以往一樣與 dApp 互動；然後再升級 dApp 的用戶介面，加入對抗量子錢包的支援。

然而，在某些情況下，可能有必要實作一個不兼容傳統錢包的獨立抗量子版本 dApp，以確保抗量子合約不受傳統合約影響。值得注意的是，QDay 對於 dApp 是否、何時及如何升級為抗量子版本並無任何限制，選擇權交由 dApp 開發者決定。

<a id="sec-5-6"></a>
### 5.6. 設計原則 {/* #56-the-design-principles */}

QDay 第 2 階段的設計遵循以下核心原則：

1. **向後兼容**
    - 傳統帳戶及錢包無需修改即可繼續運作。
    - 傳統智能合約保持完全可用。
    - 現有 dApp 可逐步過渡至抗量子版本。
2. **安全隔離**
    - 抗量子帳戶與傳統帳戶完全獨立（只共用助記詞）。
    - 抗量子智能合約不會因傳統密碼原語而受損。
    - 抗量子交易類型與傳統交易類型清晰分隔。
3. **無縫用戶體驗**
    - 同一組助記詞可同時衍生傳統帳戶及抗量子帳戶。
    - 抗量子錢包可選擇支援傳統操作。
    - 有需要時，在傳統帳戶與抗量子帳戶之間自動遷移資產。
4. **高效實作**
    - 抗量子簽名驗證內置於 QDay 節點。
    - 抗量子操作需額外的 Gas 成本。
    - 抗量子合約方法採用標準化前綴（`pq_`）。
5. **靈活採用**
    - dApp 開發者可自行決定升級時間表。
    - 提供多種實作方式（逐步升級或全面替換）。
    - 可選的後備機制，以兼容傳統系統。
6. **清晰標準**
    - 抗量子方法採用一致的命名慣例。
    - 標準化的簽名數據格式。
    - 傳統組件與抗量子組件之間有明確定義的介面。

這些原則確保 QDay 能過渡至抗量子安全，同時保持易用性，並讓生態系統自然成長。

## 6. 應用生態系統 {/* #6-application-ecosystem */}

## 7. 新的演進：抗量子全球支付網絡（第 1.5 階段） {/* #7-a-new-evolution-quantum-resistant-global-payment-network-phase-15 */}

<a id="sec-7-1"></a>
### 7.1. 願景：量子時代的通用平台 {/* #71-vision-a-universal-platform-for-the-quantum-era */}

QDay 的構想不止於成為全球首個抗量子、兼容 EVM 的 Layer 2。其長遠願景是將 QDay 定位為一個通用應用平台——能夠在單一而連貫的生態系統內承載支付、去中心化金融、商業及 AI 原生服務。

此生態系統內的所有應用均具備兩項基礎特性：以太坊虛擬機（EVM）的完整表達能力，以及承襲自 Layer 1 Abelian 區塊鏈的後量子安全保障。

此願景的核心，是讓鏈擁有自己安全、合規且由法定貨幣支持的原生穩定幣。這種穩定幣可在所有應用類別之間——由消費者支付到自主代理商業——實現順暢而穩定的價值交換，而無需用戶或代理接觸價格波動的原生代幣。結合 QDay 的抗量子基礎設施，擁有這種原生穩定幣使平台成為全球數碼貨幣流動中可信而安全的基礎。

總括而言，團隊在 QDay 這一發展階段的使命是：

> **讓 QDay 成為全球首條具備原生代理支付能力的抗量子支付區塊鏈，由其自身的原生穩定幣驅動，並以錨定於 Abelian Layer 1 的 ZK 證明保障安全。**

<a id="sec-7-2"></a>
### 7.2. 主要行業趨勢的匯聚 {/* #72-convergence-of-major-industry-trends */}

QDay 下一個戰略篇章由三大行業趨勢塑造。這些趨勢互相強化，並正加速推動市場對 QDay 所設計提供的基礎設施的需求。

#### 趨勢 1——AI 與自主代理的崛起 {/* #trend-1--the-rise-of-ai-and-autonomous-agents */}

人工智能系統已不再是只會回應人類查詢的被動工具。現代 AI 代理會代表用戶自主規劃、決策和行動——安排會議、執行交易、管理工作流程，並且愈來愈多地在無需人類逐步介入的情況下進行購買和資金轉帳。AI 由軟件工具轉變為經濟參與者的進程已經展開。

這一轉變對區塊鏈基礎設施有直接影響：AI 代理需要以機器速度運作、具備可編程規則、消費上限及密碼學身份的支付通道。傳統金融系統並非為此而設計。能提供可編程、低成本且具身份識別能力的支付基元的區塊鏈網絡，有望成為代理經濟的結算層。QDay 憑藉其 EVM 可編程性、穩定幣基礎設施及即將推出的代理專屬功能，正是為擔當這一角色而設計。

> **數據點：** 2026 年 6 月，自動化機器流量佔全球網絡請求的 57.4%（即多於人類流量）。預計 2026 年代理式 AI 支出將達 2,019 億美元。自主軟件需要能以機器速度結算、無需人手介入的支付通道。（資料來源：Cloudflare、Gartner）

#### 趨勢 2——美元透過穩定幣數碼化 {/* #trend-2--the-digitization-of-the-us-dollar-via-stablecoins */}

與美元錨定的穩定幣——最著名的是 USDC 和 USDT——合計市值已達數千億美元，每年在公共區塊鏈上處理數萬億美元的結算量。其監管走向亦已根本轉變：美國已制定正式承認支付穩定幣的立法框架，歐洲和香港亦然。英國、阿聯酋、新加坡及日本等其他主要經濟體亦正推行同類框架。

穩定幣如今不僅是加密原生工具，更是可編程的美元通道：它們以遠低於代理銀行的成本和延遲結算國際 B2B 支付，讓新興市場的創作者無需本地銀行服務亦能變現，並正被直接整合到 Visa 的卡結算基礎設施中。美國政府已明確承認穩定幣是擴大美元計價工具全球覆蓋面和需求的機制。

QDay 自身的原生穩定幣，使平台處於這一結構性轉變的交匯點；整個 QDay 支付生態系統亦據此設計，讓代理、用戶及機構能在量子安全的網絡上以數碼美元進行交易。

> **數據點：** 2026 年 6 月，穩定幣結算額達 9 萬億美元，經調整（反映實際經濟用途）的交易量為 1.79 萬億美元，市值超過 3,100 億美元。預計至 2030 年穩定幣總市值將達 1.9 萬億美元。（資料來源：Visa、Citi）

#### 趨勢 3——代理支付的興起 {/* #trend-3--the-emergence-of-agentic-payments */}

為回應代理經濟，支付基礎設施正經歷根本性的重新設計。Stripe、Google、Coinbase 以及愈來愈多金融科技公司已宣佈或部署代理專屬的支付基元：讓 AI 代理持有餘額、發起轉帳、按請求支付 API 調用費用，並代表其委託人收取價值的 API——全部無需人類授權每一筆交易。

HTTP 402 支付協議（「x402」）已成為將穩定幣支付嵌入普通網絡請求的新興標準：代理調用 API，伺服器回應付款請求，代理以 USDC 付款，隨即獲得存取權限——全部在單一 HTTP 交互內完成，無需管理 API 密鑰，亦無訂閱負擔。主要雲端及支付供應商的研究顯示，互聯網流量中由 AI 代理而非人類產生的比例正不斷上升，而且增長迅速。服務這類流量的支付基礎設施必須可編程、低延遲，並能以機器速度和機器規模運作。QDay 的設計正是要原生參與這一新興的代理支付格局。

> **數據點：** 自 2025 年 5 月推出以來，代理透過 x402 協議已完成 1.76 億筆交易、結算金額逾 7,300 萬美元，目前約有 3,900 個商戶透過此標準接受付款。（資料來源：Coinbase）

### 7.3. 戰略前路 {/* #73-the-strategic-path-forward */}

#### 遷移至 Polygon CDK {/* #migration-to-polygon-cdk */}

QDay 下一階段的基礎步驟，是將 QDay 區塊鏈遷移至 Polygon Chain Development Kit（CDK）。這是一項戰略性基礎設施決定，對 QDay 的性能和支付能力有廣泛的後續影響。

Polygon CDK 是一套開源工具包，用於將主權、兼容 EVM 的區塊鏈部署為 ZK Rollup。CDK 鏈保留完整主權——擁有自己的原生代幣（$QDAY）、自己的驗證者集合和自己的治理——同時連接至名為 AggLayer 的共享互操作層。此遷移並非取代 QDay 現有架構，而是以本節所述的功能升級其結算及證明機制。

基於 CDK 的 QDay 鏈的主要特點：

- **高吞吐量：** 預設 CDK 模式約每秒 2,000 筆交易；配合優化基礎設施可達 20,000 TPS。
- **低交易手續費：** 每筆交易平均手續費由不足一仙至數仙不等，令微交易及代理小額支付在大規模下具經濟可行性。
- **亞秒級支付結算**（就 QDay 鏈本身而言，不包括向 L1 Abelian 區塊鏈提交證明）。
- **Validium 模式：** 交易數據可儲存於鏈下，只將 ZK 證明發佈至結算層，在保持密碼學完整性的同時保障私隱。
- **兼容 EVM：** 完全兼容以太坊開發工具鏈——所有現有 QDay 智能合約、dApp 及開發者工具均無需修改即可遷移。
- **基於 ZK 證明的結算：** 每批 QDay 交易均附有零知識有效性證明，經證明聚合層路由，再將合併證明提交至 Abelian 區塊鏈——保留 QDay 安全模型核心的抗量子結算保障。

#### 代理支付能力 {/* #agentic-payment-capabilities */}

- **錢包基礎設施：** 企業級智能合約錢包，配備嵌入式 SDK、Gas 抽象（在代理支付流程中，用戶以 QDay 原生穩定幣而非原生 Gas 代幣支付手續費）、基於 Passkey 的身份驗證及消費控制。AI 代理可獲分配限定會話範圍的錢包，並可設定消費上限及有效期。
- **合規與身份：** 透過 ERC-8004 進行鏈上代理身份註冊，讓代理建立可攜的聲譽，並獲交易對手及服務信任。
- **結算通道：** QDay 自身的鏈提供快速、低成本的結算——亞秒級速度、低於一仙的手續費——作為所有支付流程的基礎層。
- **x402 代理支付協議：** HTTP 402 支付標準讓 AI 代理透過普通 HTTP 調用，以 QDay 原生穩定幣按 API 請求付款。代理發出數據請求、推理調用或服務調用時，可即時以 QDay 原生穩定幣付款，無需事先協議、訂閱或管理 API 密鑰。

#### 為代理經濟而設的 QDay 原生穩定幣 {/* #qdays-native-stablecoin-for-the-agent-economy */}

QDay 將擁有自己與美元錨定的原生穩定幣，作為平台上所有支付活動的主要記帳單位。在代理經濟的背景下，這種穩定幣具備數項不同功能：

- **Gas 抽象：** 在 QDay 整合及使用 Paymaster 基礎設施後，代理和用戶可用原生穩定幣支付交易手續費，在代理支付流程中的日常操作無需持有或管理 $QDAY 原生代幣。從代理的角度看，每次互動都以穩定幣計算——根本沒有 Gas 代幣的概念。
- **AI 代理金庫：** 代理可在其限定會話範圍的錢包中持有穩定幣餘額，在設定的上限內消費，並收取穩定幣作為所提供服務的報酬——構成無需人類介入的完整經濟生命週期。
- **跨境支付：** QDay 上的穩定幣轉帳可在一秒內結算，手續費低於一仙，適用於跨境 B2B 及消費者支付流程；相比之下，傳統支付通道的結算需時數天，手續費達 1-3%。
- **DeFi 抵押品：** 在 QDay 的 DeFi 生態系統（QDay Swap、QDay Lending（計劃中）等）內，原生穩定幣將作為主要的穩定抵押品，以美元計價的工具支援借貸及流動性提供，而無需承受加密貨幣價格波動的風險。

### 7.4. QDay 的差異化優勢：量子安全支付 {/* #74-the-qday-differentiator-quantum-secure-payments */}

QDay 在全球支付格局中最重要的戰略差異，是目前其他支付區塊鏈都不具備的——後量子密碼學安全：在第 1 階段錨定於專為抗量子而建的 Layer 1，並在第 2 階段成為原生後量子。

#### QDay 獨特的安全架構 {/* #qdays-unique-security-architecture */}

在第 1 階段，QDay 以 EVM Layer 2 鏈的形式運作，待 PQZK Bridge 框架實作後，其最終狀態將透過該框架結算於 Abelian L1；該 L1 鏈採用被美國國家標準與技術研究院（NIST）列為抗量子的格密碼算法（LWE 及 Ring-LWE）。

關鍵特性是由結算於 Abelian L1 的 ZK 證明支持的跨鏈最終確定性。一批 QDay 交易一經證明並提交至 Abelian，該狀態的最終確定性即受抗量子密碼學保護。擁有量子電腦的攻擊者無法偽造 Rollup 營運者在 Abelian 層的簽名，無法為無效的狀態轉換產生有效的 PQZK 證明，因此即使擁有量子運算資源，亦無法修改或撤銷已確認的 QDay 交易。

此特性在現時市場上為 QDay 所獨有。競爭對手的支付區塊鏈和 L2 方案均結算於以太坊或其他 L1，其密碼學假設屬於經典類別，因此在能力足夠的量子電腦面前存在漏洞。QDay 是唯一將最終確定性錨定於後量子密碼學的 EVM 兼容支付網絡。

#### 抗量子代理商業 {/* #quantum-resistant-agentic-commerce */}

AI 代理與抗量子支付的結合，是一個格外重要的研究方向。隨着 AI 代理成為經濟參與者——持有餘額、發起付款及管理財務倉位——其所用密鑰和錢包的安全變得至關重要。能夠破解橢圓曲線密碼學的量子電腦，原則上可以從任何標準 EVM 錢包的公鑰推導出其私鑰。對於大規模自主運作的 AI 代理而言，此類攻擊的後果將會嚴重，甚至可能無法挽回。

QDay 的路線圖直接應對這一問題。第 2 階段的抗量子帳戶模型——引入後量子密鑰、抗量子錢包及抗量子智能合約——將擴展至涵蓋代理錢包基礎設施。在 QDay 上運作的 AI 代理將能在抗量子帳戶中持有穩定幣餘額，並由抗量子智能合約執行限定會話範圍的消費上限。保護這些帳戶的私鑰由格密碼保障，無論對經典還是量子攻擊者而言都難以破解。

結合第 1 階段所述基於 DAO 的 Rollup 暫停機制，QDay 為量子級威脅提供完整的應對框架：偵測、暫停、凍結、補救及恢復——而量子電腦無法繞過其中任何一步，因為每一步都需要 Rollup 營運者的抗量子簽名。

### 7.5. 研發重點領域 {/* #75-research-and-development-focus-areas */}

隨着 QDay 朝其完整的支付及代理商業願景演進，以下是團隊目前積極推進的研發方向：

1. **CDK 遷移**——完成 QDay 區塊鏈遷移至 Polygon CDK，並實作 PQZK Bridge 框架以將 ZK 證明錨定於 Abelian。這是其後代理支付能力的基礎設施根基。
2. **原生穩定幣基礎設施**——與 Open Money Stack（OMS）層整合。建立 QDay 的 Paymaster 基礎設施，讓鏈上穩定幣可用作原生 Gas 代幣。
3. **代理錢包服務**——設計及實現限定會話範圍、抗量子的代理錢包，支援可設定的消費上限及限時存取窗口；並與 x402 協議整合，實現按請求的穩定幣支付。
4. **鏈上代理身份（ERC-8004）**——在 QDay 上部署 ERC-8004 代理身份標準，讓 AI 代理註冊可驗證的身份、建立可攜的聲譽，並獲交易對手信任。
5. **機構支付私隱層**——研究 ZK 屏蔽池技術，以在 QDay 上實現機密的機構支付流程：支付金額及交易對手地址不向公眾披露，但仍可供獲授權的審計人員驗證。

### 7.6. 總結 {/* #76-summary */}

QDay 的下一個創新篇章，由三股匯聚的力量——AI 代理經濟、美元穩定幣的全球普及，以及對量子安全金融基礎設施的需求——以及針對每股力量的清晰戰略回應所界定。

遷移至 Polygon CDK 釋放所需的吞吐量，並成為代理支付基礎設施的基礎。擁有自己的原生穩定幣，提供代理、用戶及機構在不受價格波動影響下進行交易所需的穩定、以美元計價的貨幣單位。而獨特的抗量子安全架構——EVM Layer 2 執行，配合錨定於 Abelian 區塊鏈的 ZK 證明最終確定性——提供了目前全球其他支付網絡都無法提供的密碼學保證水平。

QDay 將成為全球首條具備原生代理支付能力的抗量子支付區塊鏈：在這個平台上，AI 代理以 QDay 的穩定幣支付服務費用，跨境結算在兩秒內以低於一仙的成本完成確認，而每筆交易的最終確定性最終都由後量子密碼學保障，足以抵禦未來十年預期中最強大的運算攻擊者。

## 9. 結論 {/* #9-conclusion */}

QDay 代表區塊鏈技術的突破性進展，提供首個可擴展且高性能的抗量子、兼容 EVM 的 Layer 2 方案。透過務實的多階段實施策略，QDay 在保留現有區塊鏈基礎設施實際優勢的同時，應對量子運算威脅這一關鍵挑戰。

第 1 階段透過 L1 輔助 Rollup 建立抗量子帳本安全，借助 Abelian 的抗量子特性，同時保持完整的 EVM 兼容性。創新的 POS-over-POW 共識機制結合工作量證明的安全優勢與權益證明的效率優勢，形成獨特而穩健的安全模型。抗量子 Rollup 的實施提供額外一層保護，既能安全處理交易，亦能在偵測到威脅時暫停運作。

第 2 階段將量子安全推進至帳戶層面，引入抗量子帳戶、錢包及智能合約，同時保持與舊有系統的向後兼容。這種創新與兼容之間的審慎平衡，確保現有用戶和開發者能順利過渡，同時為有需要的人提供更強的安全功能。

在兩者之間，新加入的第 1.5 階段回應了在 AI 需求、代理支付及代理商業日益增長的情況下，對安全、高性能支付通道與日俱增的需要。

QDay 全面的生態系統策略——包括必要的 DeFi 應用及跨鏈橋——打造出完整的抗量子區塊鏈環境。平台的代幣經濟模型採用均衡的分配策略，確保長遠可持續發展，並鼓勵整個網絡的廣泛參與。

QDay 的路線圖勾劃出邁向全面實施的清晰路徑，並審慎注重測試、逐步部署及生態系統發展。這種有條不紊的方針，結合平台的創新技術特點，使 QDay 成為抗量子區塊鏈技術的先驅，準備好應對不斷演變的區塊鏈格局中當前的需求和未來的挑戰。

在近期路線圖以外，QDay 團隊正積極推進一個戰略研發方向，把平台的抗量子基礎延伸至全球穩定幣支付及 AI 原生商業的新興領域。此研究方向的目標清晰明確——將 QDay 建立為全球首個具備原生代理支付能力的抗量子全球支付網絡，為個人、企業及自主 AI 代理提供一個平台，讓數碼商業快速、低成本，並且不受更廣泛的金融及區塊鏈領域尚未應對的量子威脅影響。

憑藉抗量子、可擴展性及實用性的結合，QDay 不僅是漸進式的改良，更是區塊鏈技術的根本性進步，為去中心化應用及數碼資產開創更安全、更可持續的未來。
