# ABEL 質押使用指南

## 簡介：ABEL 質押如何運作

質押就像把你的數位資產存入高收益的儲蓄帳戶。作為將代幣「鎖定」一段時間的回報，你每天都能獲得獎勵。

### 三步驟流程：

1. **設定你的數位錢包**：你將使用 MetaMask 來持有與管理資金。
2. **轉換你的代幣**：你必須將標準的 ABEL 代幣轉換為 WABEL，才能在質押網路上使用。
3. **存入並賺取**：選擇要質押的代幣數量與鎖定期限，即可開始賺取獎勵。

:::warning[重要提醒]
你無法直接使用標準的 Abelian 行動錢包 App 在本網站進行質押。由於 Abelian 網路在技術上與網頁錢包所使用的系統不同，你必須使用 MetaMask 並依照下方說明完成 WABEL 轉換流程。
:::

## 先決條件

開始質押前，請確認已備妥以下項目：

- 一個 EVM 相容錢包（建議使用 MetaMask），並已啟用 QDay Aevum。
- 錢包中持有 WABEL 代幣（透過 QDay Bridge 從 Abelian 網路轉換而來的 ABEL）。
- 少量 WABEL，用於支付 QDay 網路上的交易手續費。

### 如何取得 WABEL？

若你尚未持有 WABEL，請前往 **[WABEL 轉換頁面](https://portal.qday.io/en/abel-conversion)**，將你的 ABEL 跨鏈轉換為 WABEL。

## 教學

依照以下步驟開始質押：

### 步驟 1：錢包設定

登入 MetaMask，並將 QDay Aevum 新增為自訂網路。詳細說明請參閱 [MetaMask 錢包使用指南 - 新增 QDay 網路](/guide/handbook/user-guide/metamask#將-qday-網路新增至-metamask)。

### 步驟 2：進入質押頁面

- 前往 https://portal.qday.io/
- 點選左側導覽選單中的 **「Staking」** 進入質押頁面。

  ![Staking portal homepage](/qday/staking/portal-2.png)

- 點選 **「Connect Wallet」** 連接你的錢包。

  ![Connect wallet options](/qday/staking/qday-connect-wallet-dialog.png)

### 步驟 3：質押

#### 質押

- 在「Select Token」下拉選單中選擇 **WABEL**。

  ![WABEL staking interface](/qday/staking/wabel-staking.png)

- 當你的 WABEL 餘額充足時（最低質押數量：1,000 WABEL），輸入要質押的數量、選擇鎖定期限，然後點選 **「Stake」** 並在錢包中確認。

#### 我的質押（My Staking）

質押完成後，你可以在「My Staking」分頁查看詳細資訊：

- **每日獎勵自動累積** → **Claim**（領取）你的待領獎勵 → **Withdraw**（提領）將金庫餘額轉至你的 EVM 錢包。
- 每筆紀錄會顯示質押數量、鎖定期限與剩餘天數，並提供以下操作：
  - **Extend Lock Period（延長鎖定期限）**：延長鎖定時間以持續累積獎勵。
  - **Add Stake（增加質押）**：向既有部位追加代幣，以提高每日獎勵。
  - **Unstake（解除質押）**：鎖定期限屆滿後提領已質押的代幣。鎖定期間無法使用。

#### 儀表板（Dashboard）

點選左側導覽選單中的 **「Dashboard」** 分頁，即可全面檢視你所有的質押資產。

## 認識你的獎勵

- **倍數**：你承諾鎖定代幣的時間越長，每日的「薪資」就越高。例如，選擇鎖定 4 年可讓你在獎勵份額上獲得 1500% 的倍數。
- **每日發放**：你不必等上數年才能看到進展。即使主要存款處於鎖定狀態，獎勵仍會每天累積並發放。
- **隨時提領**：你可以隨時「Claim」獎勵並轉入錢包，而不影響已鎖定的存款。
- **鎖定期加權**：系統設計上偏向長期支持者；鎖定期越長，份額分配越高。
- **獎勵浮動**：以上數字描述的是質押倍數結構。實際獎勵並無保證，可能會依總池參與度、網路狀況及你所選的鎖定期限而有所不同。

## 常見問題（FAQ）

### Q1：可以將 Abelian 網路新增至 MetaMask 嗎？

**答**：不行。

Abelian 是一個獨立的後量子區塊鏈網路，採用與 EVM 不同的技術架構。MetaMask 專為 Ethereum 虛擬機（EVM）相容鏈設計，因此無法支援 Abelian 網路。

:::warning[注意]
若你需要使用 Abelian 網路（例如持有 ABEL 以進行跨鏈轉換），請使用 [Abelian 行動錢包應用程式](/guide/handbook/user-guide/abelian-mobile-wallet)。
:::

### Q2：WABEL 的最低質押數量是多少？

**答**：最低質押數量為 **1,000 WABEL**。
