# 使用指南

QDay 日常操作的逐步指南——錢包、兌換、質押與跨鏈。初次使用？請先閱讀[快速開始](/guide/handbook/getting-started)，或[將 QDay 新增至你的錢包](/guide/start/add-network)。

## 本節指南

### 錢包

- **[MetaMask 錢包](metamask)** — 安裝 MetaMask、新增 QDay 網路並匯入代幣
- **[Abelian Mobile Wallet](abelian-mobile-wallet)** — 在 iOS 或 Android 上管理 ABEL 與 QDAY

### 賺取收益

- **[兌換（Swap）](swap)** — 交易 WABEL、QDAY 與 USD8，或提供流動性
- **[QDAY 質押](qday-staking)** — 質押 QDAY / WQDAY 以獲得協定獎勵
- **[ABEL 質押](abel-staking)** — 將 ABEL 轉換為 WABEL 並在 QDay 上質押

### 跨鏈橋

- **[Abelian Bridge v3](abelian-bridge-v3)** — 在 Abelian 與 QDay 之間轉移 ABEL ↔ WABEL
- **[QDay Bridge](#qday-bridge)** — 在 EVM 鏈之間轉移 ERC20、TRC20 與 QRC20 代幣

## 區塊瀏覽器

QDay 的區塊瀏覽器可讓你查詢網路上的任何交易、地址或合約。

| | URL |
|---|---|
| 測試網（QDay Aevum） | [explorer-test.qday.info](https://explorer-test.qday.info) |
| 主網 | 即將推出 |

- **搜尋** — 將交易雜湊、錢包地址或合約地址貼入搜尋列。
- **交易** — 檢視狀態、區塊確認、Gas 費用與代幣轉移。
- **地址詳細資訊** — 查看 QDAY、WABEL 與 USD8 餘額、歷史紀錄，以及已驗證的合約原始碼（若有）。
- **網路統計** — 在首頁查看目前區塊高度、平均出塊時間與吞吐量。

## QDay Bridge

QDay Bridge 與 [Abelian Bridge](abelian-bridge-v3) 是兩個獨立的產品。其他相容 EVM 鏈上的 ERC20、TRC20 與 QRC20 資產請使用 QDay Bridge；ABEL / WABEL 請使用 Abelian Bridge。

入口網站：[portal.qday.io/en/bridge](https://portal.qday.io/en/bridge)

1. 前往 QDay Bridge 並連接錢包。
2. 選擇你要跨出的來源鏈與網路，以及要跨入的目標鏈與網路。
3. 選擇代幣並輸入要跨鏈的數量。
4. 檢查目標錢包地址、預估費用與完成時間，然後確認。
5. 在錢包中核准交易。依目標鏈的不同，你可能需要確認第二筆交易才能完成轉移。
6. 在跨鏈橋的交易歷史中追蹤轉移狀態，直到完成為止。
