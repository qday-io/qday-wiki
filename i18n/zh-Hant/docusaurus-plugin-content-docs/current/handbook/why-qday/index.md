# 為什麼選擇 QDay

## QDay 與 Ethereum 的比較

| | Ethereum | QDay |
|---|---|---|
| 速度 | 基礎層約每秒 15–30 筆交易 | 目前每秒數千筆交易，設計上可擴展至每秒數萬筆 |
| 費用 | 網路繁忙時可能急遽上升 | 設計上維持低廉且可預期——每筆交易僅需不到一美分至數美分 |
| 最終性 | 完整結算約需 12–15 分鐘 | 在 QDay 本身不到一秒，並在稍後將結算錨定至 Abelian |
| 智慧帳戶 | 可選的附加功能，多數錢包預設不使用 | 內建智慧合約錢包，Gas 以 QDAY 支付（代理發起的付款則以 USD8 支付），並支援 passkey 登入與消費限額 |
| 量子安全性 | 依賴未針對量子電腦設計的密碼學 | 從一開始就以抗量子密碼學保護結算 |
| AI 代理 | 無原生支援 | 內建 AI 代理的身分與支付基礎設施 |
| 支付 | 可行，但成本與速度限制了頻繁或小額付款 | 圍繞 USD8 建構——一種為日常與機器速度支付而設計的原生穩定幣 |
| 日常體驗 | 助記詞與手動管理手續費 | 設計上更簡單：可預期的 QDAY Gas 費用、passkey 登入 |

## QDay 與一般 EVM 鏈的比較

Polygon、BNB Chain、Arbitrum、Optimism、Base 與 Avalanche 都是廣泛使用的 EVM 相容鏈，而它們多數都在同一件事上競爭：成為比 Ethereum 更快、更便宜的替代方案，同時沿用相同的帳戶安全模型，且沒有任何專為 AI 代理打造的功能。

QDay 的不同之處，在於將這些鏈無法同時提供的四件事結合在一起：AI 代理的原生基礎設施、以原生穩定幣 USD8（而非價格波動的原生代幣）為核心的支付系統、由抗量子密碼學保護的結算，以及完整的 EVM 相容性。快速與低廉只是 QDay 的起點——不是它的賣點。

## 核心特色

### zk 證明

QDay 使用零知識 rollup 技術將交易打包，並在不揭露底層資料的情況下證明其有效性，再將該證明結算至 Abelian。這讓交易保持快速且低廉，同時獲得與 Abelian 本身相同的抗量子保證——這些證明的建構方式，使得即使擁有量子電腦的攻擊者也無法偽造。

### ML-DSA-65

QDay 結算所依賴的 Layer-1 鏈 Abelian，採用晶格密碼學——具體來說是 Learning-With-Errors（LWE）與 Ring-LWE 問題——這是 NIST 認可為可抵抗量子攻擊的數學方法，而非當今多數區塊鏈所使用的橢圓曲線密碼學。QDay 也正在將抗量子帳戶直接建構到自身的層級中：一種新的帳戶類型，由使用者現有帳戶的同一組助記詞產生，並使用獨立於標準帳戶的抗量子金鑰（ML-DSA-65）。兩者可以並存，資產也可以在兩者之間移轉，因此採用抗量子安全性不需要放棄現有錢包。

如果 QDay 上的 dApp 遭到攻擊，受影響的帳戶可以被凍結，網路也可以在事件處理期間暫停該 rollup 的處理——而由於這種暫停依賴抗量子簽章，攻擊者即使能使用量子電腦也無法強行解除。

### ERC-4337

QDay 錢包是智慧合約（ERC-4337 帳戶抽象），而非單純的金鑰對：手續費可以用 USD8 支付而無需另外的 Gas 代幣，登入可以使用裝置 passkey 而非助記詞，AI 代理也可以擁有自己的錢包，並設定消費限額與有效期限。

### AI 代理

QDay 讓 AI 代理能以直接、原生的方式進行交易：一套鏈上身分標準，讓代理能建立可驗證的信譽；以及一套支付協定，讓代理能在單一請求中支付 API 呼叫或服務的費用——以 USD8 支付，無需訂閱或手動核准。

### 支付

USD8 是 QDay 與美元掛鉤的原生穩定幣，也是價值在網路上流動的主要方式——無論是消費者付款、商家結算，還是機器速度的代理付款皆然。手續費以 USD8 而非價格波動的原生代幣支付，跨境轉帳設計上可在數秒內完成結算，成本與延遲遠低於傳統銀行管道。
