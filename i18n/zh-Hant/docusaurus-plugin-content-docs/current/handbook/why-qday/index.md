# 為甚麼選擇 QDay

## QDay 與以太坊比較 {/* #qday-vs-ethereum */}

| | 以太坊 | QDay |
|---|---|---|
| 速度 | 基礎層約每秒 15–30 筆交易 | 目前每秒數千筆交易，設計上可擴展至每秒數萬筆 |
| 手續費 | 網絡繁忙時可能急升 | 設計上保持低廉且可預期——每筆交易手續費低於一仙 |
| 最終確定性 | 完整結算約需 12–15 分鐘 | 在 QDay 本身不足一秒，其後不久便將結算錨定至 Abelian |
| 智能帳戶 | 可選的附加功能，大多數錢包預設不使用 | ERC-4337 智能合約錢包，支援 Paymaster Gas 抽象（手續費可以原生穩定幣 USD8 而非 $QDAY 支付）、會話密鑰及消費限額——已於 QDay Aevum 測試網上線；主網於 2027 年第一季推出 |
| 量子安全 | 依賴並非為抵禦量子電腦而設計的密碼學 | 從一開始便以抗量子密碼學保護結算 |
| AI 代理 | 沒有原生支援 | 內置 AI 代理的身份及支付基礎設施——AI 代理錢包、會話密鑰及 x402 facilitator 已於 QDay Aevum 測試網上線；主網於 2027 年第一季推出 |
| 支付 | 可行，但成本與速度限制了頻繁或小額付款 | 圍繞 USD8 建構——一種為日常及機器速度支付而設計的原生穩定幣 |
| 日常體驗 | 助記詞及手動管理手續費 | 設計上更簡單：可透過 Paymaster Gas 抽象以 USD8 穩定幣支付手續費、passkey 登入（2027 年第一季） |

## QDay 與一般 EVM 鏈比較 {/* #qday-vs-generic-evm */}

Polygon、BNB Chain、Arbitrum、Optimism、Base 及 Avalanche 都是廣泛使用的 EVM 兼容鏈，而它們大多在同一方面競爭：成為比以太坊更快、更便宜的替代方案，同時沿用相同的帳戶安全機制，亦沒有任何專為 AI 代理而設的功能。

QDay 的不同之處，在於結合了這些鏈無法同時提供的四項元素：AI 代理的原生基礎設施、以原生穩定幣 USD8（而非價格波動的原生代幣）為核心的支付系統、由抗量子密碼學保護的結算，以及完整的 EVM 兼容性。快速與低廉只是 QDay 的起點——而不是它的賣點。

## 核心功能 {/* #core-features */}

### 抗量子 Rollup {/* #quantum-resistant-rollups */}

QDay 是一個以 Polygon CDK 構建的 EVM 兼容 Layer 2，會將交易打包成批次。每個批次由多個獨立驗證者檢查，並在達到 M-of-N 門檻同意後最終確定；其後 Committer 會將最終狀態根提交至 Abelian。這令交易保持快速及低廉，同時將已提交的帳本狀態錨定於 Abelian 的抗量子密碼學。

### ML-DSA-65 {/* #ml-dsa-65 */}

QDay 所結算至的 Layer-1 鏈 Abelian 採用格密碼學——具體而言是 Learning-With-Errors（LWE）及 Ring-LWE 問題——這是 NIST 認可能抵禦量子攻擊的數學方法，而非當今大多數區塊鏈所使用的橢圓曲線密碼學。QDay 亦正將抗量子帳戶直接建構到其自身的層級：一種新的帳戶類型，由與用戶現有帳戶相同的助記詞產生，並獨立於標準帳戶使用抗量子密鑰（ML-DSA-65）。兩者可以並存，價值亦可在兩者之間轉移，因此採用抗量子安全並不需要放棄現有錢包。

如果 QDay 上的某個 dApp 遭到攻擊，受影響的帳戶可被凍結，網絡亦可在處理事件期間暫停相關 Rollup 的處理——而由於這種暫停依賴抗量子簽名，攻擊者即使能使用量子電腦，也無法強行解除。

### ERC-4337 {/* #erc-4337 */}

QDay 錢包可以是智能合約（ERC-4337 帳戶抽象），而非簡單的密鑰對：透過 Paymaster Gas 抽象，手續費可以用 USD8 支付，而無需另一種 Gas 代幣；登入可使用裝置 passkey 而非助記詞；AI 代理亦可擁有自己的錢包，並設定可調整的消費限額及有效期限。AI 代理錢包及會話密鑰（一個 ERC-4337 智能合約策略引擎）以及穩定幣 paymaster 已於 QDay Aevum 測試網上線；主網部署將於 2027 年第一季跟進。

### AI 代理 {/* #ai-agent */}

QDay 讓 AI 代理以直接、原生的方式進行交易：一套鏈上身份標準（ERC-8004），讓 AI 代理能建立可驗證的信譽；以及一套支付協議（x402），讓 AI 代理能在單一請求中為 API 呼叫或服務付款——以 USD8 支付，無需訂閱或人手核准。x402 facilitator 已於 QDay Aevum 測試網上線；支付網絡的主網部署將於 2027 年第一季跟進。

### 支付 {/* #payment */}

USD8 是 QDay 與美元錨定的原生穩定幣，也是價值在網絡上流動的主要方式——無論是消費者付款、商戶結算，還是機器速度的 AI 代理支付皆然。透過 Paymaster Gas 抽象，用戶和 AI 代理可以 USD8 支付交易手續費，而毋須持有 $QDAY；而跨境轉帳設計上可在約兩秒內完成結算，成本與延遲遠低於傳統銀行支付通道。
