# 為甚麼選擇 QDay

## QDay 與以太坊比較 {/* #qday-vs-ethereum */}

| | 以太坊 | QDay |
|---|---|---|
| 速度 | 基礎層約每秒 15–30 筆交易 | 目前每秒數千筆交易，設計上可擴展至每秒數萬筆 |
| 手續費 | 網絡繁忙時可能急升 | 設計上保持低廉且可預期——每筆交易不足一美仙至數美仙 |
| 最終確定性 | 完整結算約需 12–15 分鐘 | 在 QDay 本身不足一秒，其後不久便將結算錨定至 Abelian |
| 智能帳戶 | 可選的附加功能，大多數錢包預設不使用 | 智能合約錢包，Gas 以 QDAY 支付（AI 代理發起的支付則以 USD8 支付），並支援 passkey 登入及消費限額——將於 2027 年第一季隨 QDay 主網推出 |
| 量子安全 | 依賴並非為抵禦量子電腦而設計的密碼學 | 從一開始便以抗量子密碼學保護結算 |
| AI 代理 | 沒有原生支援 | 內置 AI 代理的身份及支付基礎設施——將於 2027 年第一季隨 QDay 主網推出 |
| 支付 | 可行，但成本與速度限制了頻繁或小額付款 | 圍繞 USD8 建構——一種為日常及機器速度支付而設計的原生穩定幣 |
| 日常體驗 | 助記詞及手動管理手續費 | 設計上更簡單：可預期的 QDAY Gas 費用、passkey 登入（2027 年第一季） |

## QDay 與一般 EVM 鏈比較 {/* #qday-vs-generic-evm */}

Polygon、BNB Chain、Arbitrum、Optimism、Base 及 Avalanche 都是廣泛使用的 EVM 兼容鏈，而它們大多在同一方面競爭：成為比以太坊更快、更便宜的替代方案，同時沿用相同的帳戶安全機制，亦沒有任何專為 AI 代理而設的功能。

QDay 的不同之處，在於結合了這些鏈無法同時提供的四項元素：AI 代理的原生基礎設施、以原生穩定幣 USD8（而非價格波動的原生代幣）為核心的支付系統、由抗量子密碼學保護的結算，以及完整的 EVM 兼容性。快速與低廉只是 QDay 的起點——而不是它的賣點。

## 核心功能 {/* #core-features */}

### zk 證明 {/* #zk-proof */}

QDay 使用零知識 Rollup 技術將交易打包，並在不披露底層數據的情況下證明其有效性，然後將該證明結算至 Abelian。這令交易保持快速及低廉，同時獲得與 Abelian 本身相同的抗量子保證——這些證明的構建方式，使即使擁有量子電腦的攻擊者也無法偽造。

### ML-DSA-65 {/* #ml-dsa-65 */}

QDay 所結算至的 Layer-1 鏈 Abelian 採用格密碼學——具體而言是 Learning-With-Errors（LWE）及 Ring-LWE 問題——這是 NIST 認可能抵禦量子攻擊的數學方法，而非當今大多數區塊鏈所使用的橢圓曲線密碼學。QDay 亦正將抗量子帳戶直接建構到其自身的層級：一種新的帳戶類型，由與用戶現有帳戶相同的助記詞產生，並獨立於標準帳戶使用抗量子密鑰（ML-DSA-65）。兩者可以並存，價值亦可在兩者之間轉移，因此採用抗量子安全並不需要放棄現有錢包。

如果 QDay 上的某個 dApp 遭到攻擊，受影響的帳戶可被凍結，網絡亦可在處理事件期間暫停相關 Rollup 的處理——而由於這種暫停依賴抗量子簽名，攻擊者即使能使用量子電腦，也無法強行解除。

### ERC-4337 {/* #erc-4337 */}

隨着 QDay 主網於 2027 年第一季推出，QDay 錢包將會是智能合約（ERC-4337 帳戶抽象），而非簡單的密鑰對：Agent Payment 應用中的手續費可以用 USD8 支付，而無需另一種 Gas 代幣；登入可使用裝置 passkey 而非助記詞；AI 代理亦可擁有自己的錢包，並設定可調整的消費限額及有效期限。

### AI 代理 {/* #ai-agent */}

隨着 QDay 主網於 2027 年第一季推出，QDay 將讓 AI 代理以直接、原生的方式進行交易：一套鏈上身份標準，讓 AI 代理能建立可驗證的信譽；以及一套支付協議，讓 AI 代理能在單一請求中為 API 呼叫或服務付款——以 USD8 支付，無需訂閱或人手核准。

### 支付 {/* #payment */}

USD8 是 QDay 與美元錨定的原生穩定幣，也是價值在網絡上流動的主要方式——無論是消費者付款、商戶結算，還是機器速度的 AI 代理支付皆然。在 Agent Payment 應用中，手續費以 USD8 而非價格波動的原生代幣支付（一般網絡 Gas 以 QDAY 支付），而跨境轉帳設計上可在約兩秒內完成結算，成本與延遲遠低於傳統銀行支付通道。
