# 常見問題

### 什麼是 QDay？
QDay 是抗量子、兼容 EVM 的 Layer 2——目前已在測試網（QDay Aevum）上線，主網即將推出。

### 哪些錢包支援 QDay 測試網？要怎樣加入這個網絡？
QDay 測試網兼容 EVM，支援 MetaMask、WalletConnect 和 Rainbow。

網絡參數：
- **網絡名稱：** QDay Aevum
- **RPC URL：** https://rpc-test.qday.info
- **鏈 ID：** 44005
- **代幣符號：** tQDAY
- **區塊瀏覽器：** https://explorer-test.qday.info

### dApp 在新測試網的重新部署進度如何？
核心 dApp（QDay Portal、質押、QDay Swap、QDay Bridge、ABEL/WABEL Bridge）正在新的測試網叢集上重新部署及整合。

### 資產和質押要怎樣從舊的 QDay 測試網／主網遷移到新的 QDay 測試網／主網？
質押遷移橋和資產遷移橋正在部署中。待遷移橋啟用後，我們會提供逐步的遷移指南和更新版常見問題。

### WABEL 的最低質押數量是多少？
最低質押數量為 1,000 WABEL。

### 怎樣取得 QDAY 或 WQDAY 來質押？
取得 QDAY 的方法：
1. 質押 ABEL 賺取 QDAY 獎勵，
2. 透過 QDay Bridge／Abelian Mobile Wallet 取得 USD8，再在 QDay Swap 把 USD8 兌換成 QDAY。

### QDAY 的質押獎勵如何計算和發放？
在 $QDAY 的總供應量 22,517,998,100 枚之中，35.00%（7,881,299,335 枚）分配予質押獎勵類別，詳見第 3 節（代幣經濟）。
