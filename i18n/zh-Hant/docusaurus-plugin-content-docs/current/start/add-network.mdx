# 將 QDay 新增至你的錢包

一鍵將 QDay Aevum 測試網新增至 MetaMask：

<AddNetworkButton network="qday2" />

網絡即時狀態：

<LiveChainStatus network="qday2" />

:::tip[每項變更都需你核准]
此按鈕使用 EIP-3085（`wallet_addEthereumChain`）——你的錢包會在新增前顯示確認畫面，列出確切的參數。未經你的核准，不會新增任何內容。
:::

## 手動參數 {/* #manual-parameters */}

若你偏好手動新增（MetaMask → Networks → Add a network manually）：

| 欄位 | 值 |
|---|---|
| 網絡名稱 | QDay Aevum |
| 鏈 ID | `44005` |
| RPC URL | `https://rpc-test.qday.info` |
| 區塊瀏覽器 | `https://explorer-test.qday.info` |
| 貨幣 | tQDAY |

:::warning[測試網]
以上為目前的**測試網**端點——主網數值將於上線時公佈。
:::
