# 取得測試網代幣

領取測試網 **tQDAY** 作為 Gas。這個小工具會連接你的錢包、切換至 QDay Aevum 測試網，並呼叫水龍頭合約。

<FaucetWidget />

:::tip[全新錢包？]
在這裏領取屬於鏈上交易，因此需要少量 Gas。若你的錢包有 **0 tQDAY**，請先到 [faucet.qday.info](https://faucet.qday.info) 領取你的第一筆 tQDAY——它會為你支付 Gas。
:::

:::info[每個冷卻期只能領取一次]
水龍頭在鏈上對每個地址強制執行冷卻期。若你最近已領取過，它會告訴你何時可以再次領取。
:::

連接後即可查看你在 **QDay Aevum（鏈 ID 44005）** 上的即時餘額，直接從鏈上讀取——水龍頭發放的 tQDAY 就在這條鏈上：
