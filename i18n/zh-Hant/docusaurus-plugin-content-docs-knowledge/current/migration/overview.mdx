# QDay 遷移

QDay 正在升級。**QDay Aevum** 是升級後網絡的公開測試網，而升級後的 **QDay 主網**正在開發中。遷移**尚未開放**——本頁說明你可以預期的情況。

---

## 1. 目前的網絡 {/* #1-networks-today */}

| | 狀態 | 鏈 ID |
|---|---|---|
| **QDay Aevum 測試網** | **已上線**——體驗升級後的網絡、開發與測試 | `44005` |
| **QDay 主網** | 開發中——預計 2027 年第一季推出 | `44002` |

<LiveChainStatus network="qday2" />

- QDay Aevum 是**測試網**，不會取代任何現有網絡，其代幣（tQDAY、tUSD8 等）沒有實際價值。
- 現有的 QDay 網絡（主網與測試網）會繼續運作。你現有的資產目前不受任何影響。
- 將 Aevum 測試網新增至錢包**不會**轉移你的餘額。

RPC、WebSocket 與區塊瀏覽器：[鏈參數](/Knowledge/reference/chains)。新增網絡：[將 QDay 新增至你的錢包](/guide/start/add-network)。

---

## 2. 你的 QDAY：$QDAYp → $QDAY {/* #2-your-qday-qdayp--qday */}

- 現有的 QDAY 代幣現稱為 **QDAY Points（$QDAYp）**。
- QDay 主網代幣生成事件（TGE）之後，$QDAYp 可按 **1:1** 兌換為新的 **$QDAY**。
- 如你持有 **WQDAY**（例如從 QDAY 質押解除質押後取得），可在 [WQDAY Conversion](https://portal.qday.io/en/wqday-conversion) 按 1:1 轉換為 QDAY（$QDAYp）。

---

## 3. 遷移期 {/* #3-migration-window */}

QDay 主網上線後，現有用戶會在專設的 **6 至 12 個月遷移期**內轉移資產（[常見問題 2.3](/guide/faq#23-what-is-the-migration-roadmap)）。遷移期開始時，詳細步驟與官方合約地址將於 [QDay Portal](https://portal.qday.io) 公佈。

:::danger[注意安全]
遷移尚未開放。請勿將資產發送至任何「遷移」合約或網站。只依循官方 QDay Portal 及官方 QDay 渠道——QDay 團隊絕不會主動私訊你，也不會要求你提供助記詞。
:::
