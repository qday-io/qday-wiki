# 簡介

QDAY 的定位、願景與技術方向。

**重點：** ZK 證明、ML-DSA-65、ERC-4337、AI 代理、支付

## 甚麼是 QDAY {/* #what-is-qday */}

QDAY 是一個抗量子、EVM 兼容的 Layer 2 網絡，建構於全球首個抗量子區塊鏈 Abelian 之上。它為一個單一且毫不妥協的目標而設計：在大規模量子電腦到來的那一天——業界稱之為「Q-Day」的時刻——依然確保鏈上價值與身份的安全。

作為 Layer 2，QDAY 為用戶與開發者帶來熟悉的 EVM 智能合約執行環境與更高的交易吞吐量，同時從 Abelian Layer 1 上已在運作的抗量子密碼學繼承其安全。

當今幾乎所有正在使用的區塊鏈都依賴橢圓曲線密碼學（ECDSA）來保護錢包與簽署交易。這套數學高效且經過實戰驗證，但已知可被執行 Shor 算法、算力足夠強大的量子電腦破解。由這些簽名所保護的資產與身份，實際上等於是在向一個期限借貸。

QDAY 的目標就是消除這個期限。QDAY 上的帳戶目前仍使用標準 ECDSA——ML-DSA-65 帳戶、後量子預編譯合約與混合簽名將於第 2 階段推出——但結算繼承了 Abelian 格密碼學（建立在 Learning-With-Errors 與 Ring-LWE 困難性假設之上）的抗量子能力。QDAY 在這個基礎之上疊加零知識 Rollup、創新的 PoS-over-PoW 共識設計，以及兩階段的抗量子帳戶模型。

簡而言之：QDAY 讓你今天就能以專為 Q-Day 之後仍保持安全而設計的密碼學與架構進行交易與開發。

## 願景與使命 {/* #vision--mission */}

**願景。**

一個基礎不會過期的數碼經濟——在邁向量子時代的轉型過程中，價值與身份始終值得信賴。

**使命。**

透過將 Abelian 的後量子密碼學基礎與 EVM 的開發者友善體驗結合，提供一個開發者與用戶都能無障礙採用的抗量子 Layer 2。

指導原則很簡單：在資產被攻破之後才到來的安全毫無價值。遷移至量子安全密碼學必須在 Q-Day 之前完成，而非之後——QDAY 的存在正是為了讓這項遷移現在就切實可行。

## 為甚麼選擇 QDAY {/* #why-qday */}

**威脅並非假設。**

「先收集、後解密」（Harvest now, decrypt later）攻擊是安全業界有據可查的隱憂：攻擊者可以在今天記錄加密數據與已簽署的交易，打算等量子硬件成熟後再加以破解。在公開區塊鏈上，每一個簽名都永久可見，這使區塊鏈成為特別暴露的攻擊目標。

**事後改造很困難。**

從底層開始建構抗量子能力才是更好的做法。QDAY 不是在既有的鏈上事後外掛後量子安全——它透過抗量子 Rollup 直接從 Abelian Layer 1 繼承抗量子能力，並在第 2 階段將這種抗量子能力延伸至帳戶與智能合約層級。

**你不應該為了可用性而犧牲安全。**

QDAY 改造 Polygon 的 ZK Rollup 技術（調整為可與 Abelian 基於 UTXO 的 Layer 1 協同運作，而非 ZK Rollup 通常所建構於其上的帳戶型 Layer 1），以維持網絡的可擴展性，同時為開發者保留完整的 EVM 兼容性。

**EVM 兼容，所以你無需從頭開始。**

作為 EVM 兼容的 Layer 2，QDAY 讓既有的 Solidity 工具、錢包與思維模式得以沿用。開發者能使用他們已熟悉的生態系統，並以 Abelian 的抗量子基礎作為後盾。

## 主要特色 {/* #key-features */}

**透過繼承而抗量子。**

QDAY 的帳本安全錨定於 Abelian 的格密碼學密鑰與算法（LWE / Ring-LWE 困難性假設），而非外掛模組。

**抗量子 ZK Rollup。**

QDAY 將 Polygon 的零知識 Rollup 技術改造以適配 Abelian 基於 UTXO 的 Layer 1。若偵測到攻擊，可以用抗量子的方式暫停 Rollup 執行——一旦暫停生效，攻擊者便無法偽造繼續轉移資金所需的簽名。

**PoS-over-PoW 共識。**

QDAY 在 Abelian 的工作量證明（PoW）Layer 1 之上疊加一套權益證明（PoS）驗證者系統——這種混合設計旨在結合 PoW 的安全保證與 PoS 的效率及可擴展性。

**EVM 兼容的 Layer 2。**

完整支援既有的 Solidity 合約與以太坊工具。

**兩階段抗量子帳戶模型。**

第 1 階段透過 L1 輔助的 Rollup 保護帳本數據。

第 2 階段（開發中）引入專屬的抗量子帳戶、錢包與智能合約——由用戶既有帳戶的同一組助記詞衍生，但在密碼學上與其相互獨立，以達到安全隔離。

**高成本效益、快速結算。**

鏈下交易處理加上 PoS 層，旨在相較於單獨使用 Abelian Layer 1 降低手續費並加快確認速度。

## 核心能力 {/* #core-capabilities */}

**後量子帳本安全**

一旦 Rollup 獲 Abelian 確認，底層帳本數據——包括待處理、尚未最終確定的交易——即受到保護，免受量子電腦輔助的攻擊，包括 51% 攻擊。

**抗量子暫停機制**

若具備量子能力的攻擊者利用漏洞，QDAY 的 DAO 可投票暫停 Rollup 執行、凍結受影響的活動並協調應對——白皮書指出，這是目前同類 Layer 2 網絡所不具備的防護措施。

**向後兼容的帳戶模型**

第 2 階段的抗量子帳戶設計為可由單一助記詞同時衍生出傳統（EVM 標準）帳戶與抗量子帳戶，讓既有用戶與錢包的遷移路徑更順暢。

**帳戶抽象** *（計劃中——將於 2027 年第一季隨 QDay 主網推出）*

採用 Alto bundler 的 ERC-4337 支援，將帶來智能帳戶、會話密鑰（Session Key）、由 Paymaster 贊助的免 Gas 交易、批次處理，以及更佳的使用體驗。

**進階應用生態系統**

QDAY 的基礎設施支援跨鏈互通（Abelian Bridge）與去中心化交易所（QDay Swap，目前已在 QDay Origin 主網上線）。高速支付能力（包括 Agent Payment）將於 2027 年第一季隨 QDay 主網推出。

**自動化與智能互動** *（計劃中——將於 2027 年第一季隨 QDay 主網推出）*

QDAY 的低延遲環境專為處理高頻互動而設計，適合鏈上自動化——AI 代理將能自主管理基於意圖的交易、執行智能合約互動，並在去中心化交易所上優化交易策略。

## 技術堆疊 {/* #technology-stack */}

QDAY 精密的模組化架構善用了現代區塊鏈技術的精華：

**Layer 1 基礎**

Abelian 區塊鏈（基於格的後量子密碼學）。

**執行與證明**

Polygon CDK、PolygonZKEVM 合約的分支實例，以及高效能的 Rust EVM 實作（qday-revm）。

**數據可用性與共識**

由 Abelian Plus Node 提供數據可用性，以 reth 負責執行、lighthouse 負責共識。

**智能錢包與 Bundler**

基於 TypeScript 的 ERC-4337 bundler（計劃中——將於 2027 年第一季隨 QDay 主網推出），以及為跨鏈橋接操作高度優化的索引器。

## 網絡路線圖 {/* #network-roadmap */}

**第 1 階段：L1 輔助的抗量子 Rollup，兼容 EVM。**

將 ZK Rollup 與 Abelian 整合，建立抗量子帳本，同時維持標準 EVM 帳戶模型。若偵測到惡意的量子異常活動，共識營運者可執行去中心化的「暫停」，凍結 Rollup 以防止資金損失，同時保持數據完整性。

**第 2 階段：L2 原生的抗量子帳戶與智能合約。**

將抗量子密碼學密鑰完整實作到用戶帳戶中。EVM 將原生升級以處理後量子算法，無縫支援傳統合約（以維持向後兼容）與高安全的抗量子合約。
