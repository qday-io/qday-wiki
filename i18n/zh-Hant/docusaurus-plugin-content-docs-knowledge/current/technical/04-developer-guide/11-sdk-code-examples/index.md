# SDK 與程式碼範例

:::note[將於 2027 年第一季推出]
QDay SDK（`@qday-io/sdk`）與 CLI（`@qday-io/cli`）將於 2027 年第一季推出，目前尚未在 npm 上發佈。本頁的程式碼展示的是計劃中的 API。
:::

只有 TypeScript / JavaScript SDK（`@qday-io/sdk`）與 CLI（`@qday-io/cli`）計劃於 2027 年第一季推出。Go、Rust 與 Python SDK 仍在計劃中，尚未發佈——以下套件名稱只是暫定名稱，日後可能變更，請勿從公開套件庫安裝名稱相似的套件。範例儲存庫將發佈於 [github.com/qday-io](https://github.com/qday-io)。

## JavaScript {/* #javascript */}

```bash
# Available Q1 2027 — not yet published on npm
npm install @qday-io/sdk
```

CommonJS 進入點：`require('@qday-io/sdk')`。

## TypeScript {/* #typescript */}

```bash
# Available Q1 2027 — not yet published on npm
npm install @qday-io/sdk
```

ESM 與型別：`import { … } from '@qday-io/sdk'`。本站的錢包、合約與支付程式碼片段皆以 TypeScript 為優先。
