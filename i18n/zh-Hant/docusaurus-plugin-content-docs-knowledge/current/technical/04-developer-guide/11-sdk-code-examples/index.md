# SDK 與程式碼範例

:::note[將於 2027 年第一季推出]
QDay SDK（`@qday-io/sdk`）與 CLI（`@qday-io/cli`）將於 2027 年第一季推出，目前尚未在 npm 上發佈。本頁的程式碼展示的是計劃中的 API。
:::

QDAY SDK 隨附多種語言的範例。完整的範例儲存庫位於 [github.com/qday-io](https://github.com/qday-io)。

## JavaScript {/* #javascript */}

```bash
# Available Q1 2027 — not yet published on npm
npm install @qday-io/sdk
```

CommonJS 進入點：`require('@qday-io/sdk')`。

## TypeScript {/* #typescript */}

```bash
# Available Q1 2027 — not yet published on npm
npm install @qday-io/sdk
```

ESM 與型別：`import { … } from '@qday-io/sdk'`。本站的錢包、合約與支付程式碼片段皆以 TypeScript 為優先。

## Go {/* #go */}

```bash
go get github.com/qday-io/qday-go-sdk
```

## Rust {/* #rust */}

```bash
cargo add qday-sdk
```

Crate：crates.io 上的 `qday-sdk`。

## Python {/* #python */}

```bash
pip install qday-sdk
```

套件：PyPI 上的 `qday-sdk`。
