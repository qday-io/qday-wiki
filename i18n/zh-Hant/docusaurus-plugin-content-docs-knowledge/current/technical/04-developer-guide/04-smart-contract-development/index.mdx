# 智能合約開發

QDay Aevum 完全兼容 Solidity。撰寫合約的方式與以太坊主網完全相同。

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.20;

contract HelloQDAY {
    string public message = "Quantum-safe by default";

    function setMessage(string calldata _msg) external {
        message = _msg;
    }
}
```

**使用 Hardhat 部署**

```javascript
// hardhat.config.js
module.exports = {
  networks: {
    qday: {
      url: "https://rpc-test.qday.info", // QDay Aevum testnet
      chainId: 44005,
      accounts: [process.env.PRIVATE_KEY],
    },
  },
};
```

```bash
npx hardhat run scripts/deploy.js --network qday
```

## 定義鏈 {/* #define-the-chain */}

<Tabs groupId="lib">
<TabItem value="viem" label="viem / wagmi">

```ts title="chains.ts"
import { defineChain } from 'viem';

export const qday = defineChain({
  id: 44005,
  name: 'QDay Aevum',
  nativeCurrency: { name: 'tQDAY', symbol: 'tQDAY', decimals: 18 },
  rpcUrls: {
    default: {
      http: ['https://rpc-test.qday.info'],
      webSocket: ['wss://rpc-test.qday.info'],
    },
  },
  blockExplorers: { default: { name: 'QDay Aevum Explorer', url: 'https://explorer-test.qday.info' } },
  testnet: true,
});
```

</TabItem>
<TabItem value="ethers" label="ethers">

```ts title="provider.ts"
import { JsonRpcProvider } from 'ethers';

export const provider = new JsonRpcProvider('https://rpc-test.qday.info', {
  chainId: 44005,
  name: 'qday-aevum-testnet',
});
```

</TabItem>
</Tabs>

以上範例以 QDay Aevum 測試網（鏈 ID `44005`）為目標。QDay 主網（鏈 ID `44002`）的參數將於上線時公佈——請參閱[鏈參數](/Knowledge/reference/chains)。用作 Gas 的測試網 tQDAY 可從 [faucet.qday.info](https://faucet.qday.info) 或文件內置水龍頭（[取得測試網代幣](/guide/start/faucet)）領取。

## 讀取合約（代幣餘額） {/* #read-a-contract-token-balance */}

<Tabs groupId="lib">
<TabItem value="viem" label="viem">

```ts
import { createPublicClient, http, erc20Abi } from 'viem';
import { qday } from './chains';

const client = createPublicClient({ chain: qday, transport: http() });

const balance = await client.readContract({
  address: '0x…token',
  abi: erc20Abi,
  functionName: 'balanceOf',
  args: ['0x…user'],
});
```

</TabItem>
<TabItem value="ethers" label="ethers">

```ts
import { Contract } from 'ethers';
import { provider } from './provider';

const erc20 = new Contract('0x…token', ['function balanceOf(address) view returns (uint256)'], provider);
const balance = await erc20.balanceOf('0x…user');
```

</TabItem>
</Tabs>

## 寫入合約（發送交易） {/* #write-a-contract-send-a-tx */}

```ts title="wagmi writeContract"
import { useWriteContract } from 'wagmi';

const { writeContractAsync } = useWriteContract();

await writeContractAsync({
  chainId: 44005,
  address: '0x…contract',
  abi,
  functionName: 'doSomething',
  args: [/* … */],
});
```
