# 經濟模型

**Gas**——QDAY2 採用與 Ethereum 相容的 Gas 模型。Gas 價格以原生 Gas 代幣計價，並遵循 EIP-1559（基礎費用 + 優先費用）。

**QDAY 代幣**——QDAY 代幣（總供應量：22,517,998,100）用於驗證者質押、治理與手續費支付。QDAY 的總供應量與 Abelian L1 上的 ABEL 一致。

**驗證者質押**——PoS 驗證者質押 QDAY 以參與 DA 層上的 CometBFT 共識。質押獎勵與質押權重及驗證者的正常運行時間成正比。

**證明者費用**——zk 證明者的節點營運者每證明一個批次，即可從協定金庫獲得費用。費率由 QDAY DAO 治理決定。
