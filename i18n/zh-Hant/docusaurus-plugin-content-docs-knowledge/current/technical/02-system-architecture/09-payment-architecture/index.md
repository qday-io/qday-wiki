# 支付架構

QDAY2 內建一流的支付層，專為高頻、低延遲的商務活動以及由代理驅動的微支付而設計。

**支付閘道（Payment Gateway）** — 統一的 API 層，將底層智慧合約互動抽象化。商家與 dApp 透過支付閘道建立付款請求，無需撰寫合約程式碼。

**結算（Settlement）** — 支付以 L2 最終性的速度完成結算（軟確認通常為數秒，ZK 驗證的最終性則為數分鐘）。結算引擎負責處理貨幣轉換、費用分配與商家撥款。

**商家（Merchant）** — 商家入駐時，會向支付閘道註冊商家地址與 webhook 端點。當付款完成最終確認時，商家會透過 webhook 收到結算通知。

**帳單（Invoice）** — 結構化的付款請求，包含金額、貨幣（PQUSD 或原生 Gas 代幣）、到期時間與中繼資料。帳單在鏈上建立，可由任何帳戶或 AI 代理支付。

**訂閱（Subscription）** — 定期付款方案以 Session Key 授權實作。訂閱者授予商家的支付合約一把 Session Key，並限制每個週期可使用的特定金額。

**代理支付（Agent Payment）** — AI 代理可在其 Session Key 授權範圍內自主發起付款。這實現了完全自主的商務活動——代理可為 API 呼叫、資料來源與服務付費，無需人工逐筆簽核交易。
