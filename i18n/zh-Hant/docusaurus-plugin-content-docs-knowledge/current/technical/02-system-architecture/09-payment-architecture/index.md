# 支付架構

:::note[計劃中——2027 年第一季]
支付層（包括 Agent Payment 及 x402 支援）將於 2027 年第一季隨 QDay 主網推出，目前尚未上線。本頁描述的是計劃中的設計。
:::

QDay 將內建一流的支付層，專為高頻、低延遲的商業交易及由 AI 代理驅動的小額支付而設計。

**支付閘道（Payment Gateway）**——統一的 API 層，將底層的智能合約互動抽象化。商戶及 dApp 透過支付閘道建立付款請求，無需編寫合約程式碼。

**結算**——付款以 L2 最終確定性的速度結算（軟確認通常只需數秒，經 ZK 驗證的最終確定性則需數分鐘）。結算引擎負責處理貨幣兌換、手續費分配及向商戶付款。

**商戶**——商戶入駐流程會在支付閘道登記商戶地址及 webhook 端點。付款最終確定時，商戶會經由 webhook 收到結算通知。

**發票（Invoice）**——結構化的付款請求，包含金額、貨幣（USD8 或原生 Gas 代幣 QDAY）、到期時間及元數據。發票在鏈上建立，任何帳戶或 AI 代理都可以支付。

**訂閱（Subscription）**——定期付款計劃以會話密鑰（Session Key）授權的方式實作。訂閱者授予商戶的支付合約一個會話密鑰，限定每個週期的特定金額。

**AI 代理支付（Agent Payment）**——AI 代理可在其會話密鑰授權範圍內自主發起付款。這實現了完全自主的商業交易——AI 代理可支付 API 呼叫、數據源及服務的費用，而每筆交易都無需人手簽核。
