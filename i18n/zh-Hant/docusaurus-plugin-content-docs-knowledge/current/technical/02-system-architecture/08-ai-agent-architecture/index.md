# AI 代理架構

:::note[計劃中——2027 年第一季]
AI 代理執行環境將於 2027 年第一季隨 QDay 主網推出，目前尚未上線。本頁描述的是計劃中的設計。
:::

QDay 將為鏈上 AI 代理提供原生執行環境。

**代理執行環境（Agent Runtime）**——AI 代理運作所在的沙盒執行環境。執行環境負責管理代理的生命週期、資源限制，以及與鏈上合約的互動。

**MCP（Model Context Protocol，模型上下文協議）**——AI 代理透過 MCP 伺服器與外部 AI 模型通訊。這套標準化協議讓 AI 代理可以呼叫 AI 推理端點、取得鏈上數據，並組合複雜的多步驟操作。

**意圖引擎（Intent Engine）**——用戶宣告高層次的意圖（例如「每當價格偏離超過 5%，就將我的投資組合重新平衡至 60% QDAY / 40% ABEL」）。意圖引擎將意圖轉換為具體的交易序列，並透過智能帳戶技術堆疊提交。

**工具呼叫（Tool Calling）**——AI 代理透過型別化的工具呼叫介面與智能合約互動。每個合約函數都以型別化工具的形式公開，AI 代理可以呼叫它、檢查返回值，並串連至後續的決策。

**記憶（Memory）**——持久的代理記憶儲存對話上下文、歷史交易數據及學習到的偏好。記憶儲存於鏈下，並附有鏈上承諾雜湊（commitment hash）以驗證完整性。
