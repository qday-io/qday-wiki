# AI 代理架構

QDAY2 為鏈上 AI 代理提供原生的執行環境。

**代理執行環境（Agent Runtime）** —— 代理運作的沙箱執行環境。執行環境負責管理代理的生命週期、資源限制，以及與鏈上合約的互動。

**MCP（Model Context Protocol）** —— 代理透過 MCP 伺服器與外部 AI 模型溝通。此標準化協定讓代理能呼叫 AI 推論端點、擷取鏈上資料，並組合複雜的多步驟操作。

**意圖引擎（Intent Engine）** —— 使用者宣告高階意圖（例如「每當價格偏離超過 5% 時，將我的投資組合重新平衡為 60% QDAY / 40% ABEL」）。意圖引擎將意圖轉換為具體的交易序列，並透過 Smart Account 堆疊提交。

**工具呼叫（Tool Calling）** —— 代理透過具型別的工具呼叫介面與智慧合約互動。每個合約函式都以具型別的工具形式公開，代理可以呼叫它、檢視回傳值，並串接至後續的決策。

**記憶（Memory）** —— 持久化的代理記憶儲存對話上下文、歷史交易資料與學習到的偏好。記憶儲存於鏈下，並在鏈上保存承諾雜湊以供完整性驗證。
