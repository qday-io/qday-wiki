# 錢包生態系統

**EOA 錢包**——由 ECDSA 保護的標準以太坊外部擁有帳戶（EOA）。任何以太坊錢包（MetaMask、Rabby、硬件錢包）只要新增網絡，即可在 QDay Aevum 上使用。即使是 EOA 帳戶，QDay Aevum 亦從 Abelian L1 繼承帳本層級的抗量子能力。

**智能帳戶錢包** *（計劃中——將於 2027 年第一季隨 QDay 主網推出）*——ERC-4337 智能帳戶（Smart Account）將提供免 Gas 交易（由 Paymaster 代付）、一鍵批次處理交易、用於定期操作的會話密鑰（Session Key），以及可編程的多重簽署恢復。智能帳戶 SDK 將讓部署智能帳戶及與之互動，就像連接標準錢包一樣簡單。

**後量子錢包（第 2 階段）**——在第 2 階段，用戶將能直接在錢包中產生 ML-DSA-65 帳戶。單一 BIP-39 助記詞將同時衍生標準 ECDSA 帳戶及抗量子的 ML-DSA-65 帳戶，讓資產可以順暢地從傳統安全遷移至後量子安全。

**AI 錢包** *（計劃中——將於 2027 年第一季隨 QDay 主網推出）*——AI 錢包將把智能帳戶與 AI 代理配對，AI 代理可以監察餘額、執行意圖、管理訂閱及發起付款——全部都在用戶定義的會話密鑰範圍內進行。AI 代理將在其授權範圍內自主運作，每項操作都無需人手簽核。
