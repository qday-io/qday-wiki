# 基礎設施

**RPC** — 公開的 JSON-RPC 端點（主網為 `https://rpc.qday.io`，測試網為 `https://rpc-testnet.qday.io`）提供完整的 Ethereum JSON-RPC API。開發者可直接連接 MetaMask、Foundry、Hardhat 及任何其他 EVM 工具。

**區塊瀏覽器（Explorer）** — QDAY2 區塊瀏覽器（`https://explorer.qday.io`）提供交易搜尋、地址檢視、合約驗證與代幣追蹤。以 Blockscout 為基礎建構，支援與 Ethereum 主網區塊瀏覽器相同的驗證流程。

**索引器（Indexer）** — 高效能事件索引器，追蹤代幣轉帳、DEX 交易、支付事件與代理動作。應用程式可透過 GraphQL API 查詢已索引的資料，無需重播鏈上歷史。

**水龍頭（Faucet）** — 測試網水龍頭（`https://faucet.qday.io`）發放測試用 QDAY 代幣與測試用 PQUSD，供開發與測試使用。
