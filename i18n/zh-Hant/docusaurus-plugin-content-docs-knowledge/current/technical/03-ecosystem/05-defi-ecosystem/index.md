# DeFi 生態系統

**Q-Swap**——採用標準 AMM 兌換路由的去中心化交易所。Q-Swap 目前在 QDay Origin 主網（鏈 ID `44001`）上運行，尚未部署於 QDay Aevum；Aevum 版本將於稍後推出。

**QLEAP——QDay Lending Ecosystem And Protocol** *（計劃中）*——借貸協議，用戶可存入資產作為抵押品並以其借款。利率根據使用率以算法釐定。

**Q-Finance** *（計劃中）*——聚合式 DeFi 入口，在單一介面內提供兌換、借貸及流動性供應。

**QDay Staking**——QDAY/ABEL 質押已於 2026 年 10 月 15 日結束，不再接受新的質押，亦不再產生獎勵。詳情請參閱 [QDAY 質押終止指南](/guide/handbook/user-guide/qday-staking)。

**包裝 ABEL（WABEL）**——WABEL 是 QDay 上的 QRC20 代幣，與 Abelian Layer 1 上的 ABEL 以 1:1 錨定。鑄造（在 Abelian 上鎖定 ABEL → 在 QDay 上收取 WABEL）及銷毀（在 QDay 上銷毀 WABEL → 在 Abelian 上收取 ABEL）由一個具備信任服務提供者（Trust Service Provider，TSP）認證的機構聯盟所營運的線上服務處理；用戶透過 [Abelian Bridge](/guide/handbook/user-guide/abelian-bridge-v3) 使用該服務。WABEL 遵循標準 ERC-20 介面。
