# DeFi 生態系

**QDay Swap** — QDAY2 代幣的去中心化交易所，支援 QDAY、wABEL（包裝版 ABEL）、PQUSD 以及跨鏈而來的 ERC-20 代幣。支援標準 AMM 兌換路由。

**QDay Lending** — 借貸協定，使用者可存入資產作為抵押品並據此借款。利率依使用率以演算法決定。

**QDay Finance** — 整合式 DeFi 入口網站，在單一介面中提供兌換、質押、借貸與提供流動性等功能。

**QDay Staking** — 在 QDAY2 上質押 ABEL 可賺取質押獎勵，同時在 L2 上保有流動性。質押部位會被代幣化，可作為其他 DeFi 協定的抵押品。

**包裝版 ABEL（wABEL）** — wABEL 是從 Abelian Layer 1 跨鏈而來、相容於 EVM 的 ABEL 表示形式。它遵循標準的 ERC-20 介面。
