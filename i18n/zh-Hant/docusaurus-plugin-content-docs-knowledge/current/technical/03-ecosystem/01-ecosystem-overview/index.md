# 生態系統概覽

QDay Aevum 是一個 EVM 兼容、抗量子的 Layer 2。其生態系統圍繞四大應用支柱設計：

1. **ZK Rollup 基礎設施**——快速、低成本的交易，錨定於 Abelian 的抗量子 Layer 1
2. **後量子帳戶**——第 2 階段基於 ML-DSA-65 的帳戶與錢包
3. **帳戶抽象**——ERC-4337 智能帳戶，提供免 Gas 體驗、會話密鑰（Session Key）及可編程授權
4. **AI 代理支付**——專為機器對機器商業交易及自主 AI 代理而設計的支付技術堆疊

每個生態系統組件都設計為與既有的以太坊工具向後兼容。
