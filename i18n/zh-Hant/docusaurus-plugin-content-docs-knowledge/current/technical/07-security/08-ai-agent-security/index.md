# AI 代理安全性

**Session key 邊界**——每個 AI 代理都只能透過使用者智慧帳戶所核發的 Session Key 運作。Session Key 指定了：允許的合約地址、允許的函式選擇器、每次呼叫的金額上限、累計消費上限，以及到期時間戳記。`EntryPoint` 會在驗證時強制執行這些限制——代理本身的程式碼無法繞過它們。

**無特權存取**——代理永遠不會持有使用者的主簽章金鑰。若代理遭到入侵，攻擊者只能在 Session Key 的範圍內行動。使用者可隨時呼叫其智慧帳戶上的 `SessionKeyManager` 來撤銷 Session Key。

**意圖稽核**——所有代理的意圖及其產生的交易都會記錄在鏈上的 Intent Registry 中。使用者可以稽核代理所做的一切，且該記錄不可竄改。

**MCP 驗證**——代理與 MCP 伺服器之間的連線使用鏈上代理身分進行驗證。超出代理授權範圍的 MCP 請求會在伺服器端被拒絕。
