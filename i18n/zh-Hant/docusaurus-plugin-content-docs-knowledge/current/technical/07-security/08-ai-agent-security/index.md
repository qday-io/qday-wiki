# AI 代理安全

:::note[計劃中——2027 年第一季]
AI 代理、會話密鑰（Session Key）及智能帳戶將於 2027 年第一季隨 QDay 主網推出，目前尚未上線。以下控制措施描述的是計劃中的安全模型。
:::

**會話密鑰邊界**——每個 AI 代理都只能透過用戶智能帳戶所核發的會話密鑰運作。會話密鑰指定了：允許的合約地址、允許的函數選擇器、每次呼叫的金額上限、累計消費上限，以及到期時間戳記。`EntryPoint` 會在驗證時強制執行這些限制——代理本身的程式碼無法繞過它們。

**無特權存取**——代理永遠不會持有用戶的主簽名密鑰。若代理遭到入侵，攻擊者只能在會話密鑰的範圍內行動。用戶可隨時呼叫其智能帳戶上的 `SessionKeyManager` 來撤銷會話密鑰。

**意圖審計**——代理的所有意圖及其產生的交易都會記錄在鏈上的 Intent Registry 中。用戶可以審計代理所做的一切，且該記錄不可篡改。

**MCP 驗證**——代理與 MCP 伺服器之間的連線使用鏈上代理身份進行驗證。超出代理授權範圍的 MCP 請求會在伺服器端被拒絕。
