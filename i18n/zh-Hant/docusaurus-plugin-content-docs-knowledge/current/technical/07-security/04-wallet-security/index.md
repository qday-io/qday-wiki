# 錢包安全

**EOA 錢包**——標準 ECDSA 錢包（MetaMask、硬件錢包）在第 1 階段完全受支援。用戶應遵循標準的以太坊錢包安全實務：大額持有使用硬件錢包，使用獨一無二的助記詞並離線保存。

**智能帳戶錢包** *（已於 QDay Aevum 測試網上線；主網於 2027 年第一季推出）*——ERC-4337 智能帳戶提供 EOA 所沒有的安全功能：為會話密鑰（Session Key）設定支出上限及時間鎖的智能合約策略引擎，以及多重簽名要求和社交復原。單一 EOA 簽署者被入侵，並不會自動危及採用門檻式擁有權策略的智能帳戶。

**後量子錢包（第 2 階段）**——在第 2 階段（Aevum 測試網 2027 年第二季；主網 2027 年第四季），用戶可建立不受量子攻擊威脅的 ML-DSA-65 帳戶。單一 BIP-39 助記詞可同時衍生 ECDSA 帳戶與 ML-DSA-65 帳戶。用戶應在 Q-Day 到來之前，將持有的資產遷移至 ML-DSA-65 帳戶。
