# 鏈參數

用於將錢包或 dApp 連接至 **QDay Aevum** 的即時端點。

<div style={{display: 'flex', gap: '0.75rem', flexWrap: 'wrap', margin: '1rem 0 1.5rem'}}>
  <AddNetworkButton network="qday2" />
</div>

| | QDay Aevum 測試網 | QDay 主網 |
|---|---|---|
| 狀態 | 已上線 | 開發中 |
| 鏈 ID | `44005`（`0xABE5`） | `44002` |
| RPC | `https://rpc-test.qday.info` | 上線時公佈 |
| WebSocket | `wss://rpc-test.qday.info` | 上線時公佈 |
| 區塊瀏覽器 | `https://explorer-test.qday.info` | 上線時公佈 |
| 原生代幣符號 | tQDAY | QDAY |
| 小數點位數 | 18 | 18 |

:::warning[連接前請核對]
請務必以本頁核對 RPC、鏈 ID 與地址——而不是以聊天訊息或隨便某個 dApp 的橫幅為準。
:::

透過錢包介面新增：[將 QDay 新增至你的錢包](/guide/start/add-network)。以程式連接：[錢包整合](/Knowledge/technical/developer-guide/wallet-integration)。代幣：[代幣清單](tokens)。

## 手動設定（EIP-3085） {/* #manual-setup-eip-3085 */}

```json title="QDay Aevum testnet (44005)"
{
  "chainId": "0xABE5",
  "chainName": "QDay Aevum",
  "rpcUrls": ["https://rpc-test.qday.info"],
  "blockExplorerUrls": ["https://explorer-test.qday.info"],
  "nativeCurrency": { "name": "tQDAY", "symbol": "tQDAY", "decimals": 18 }
}
```

`chainName` `QDay Aevum` 是文件內 **將 QDay Aevum 測試網新增至錢包** 按鈕所新增的網絡名稱，也是錢包中顯示的名稱。
