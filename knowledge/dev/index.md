# Developer Docs

QDay is fully **EVM-compatible** — your existing Ethereum tooling (MetaMask, Solidity, Hardhat/Foundry,
wagmi/viem, ethers) works as-is. Point it at the [QDay chain parameters](../reference/chains) and build.
