# Token list

Verified contracts on **QDay Origin testnet (chain ID 44003)**. They are not deployed on Origin mainnet (`44001`) or Aevum (`44005`). Switch the wallet to `44003` before using **+ Add**.

## Native

| Token | Chain | Notes |
|---|---|---|
| QDAY | 44001 Origin mainnet | Native gas — not an ERC-20 |
| QDAY | 44003 Origin testnet | Native gas — not an ERC-20 |
| QDAY | 44005 Aevum testnet | Native gas; claim from the [faucet](/guide/start/faucet) |
