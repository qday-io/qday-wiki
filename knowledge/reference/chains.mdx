# Chain parameters

Live endpoints for connecting a wallet or dApp to **QDay Aevum**.

<div style={{display: 'flex', gap: '0.75rem', flexWrap: 'wrap', margin: '1rem 0 1.5rem'}}>
  <AddNetworkButton network="qday2" />

| | QDay Aevum testnet | QDay mainnet |
|---|---|---|
| Status | Live | In development |
| Chain ID | `44005` (`0xABE5`) | `44002` |
| RPC | `https://rpc-test.qday.info` | Published at launch |
| WebSocket | `wss://rpc-test.qday.info` | Published at launch |
| Explorer | `https://explorer-test.qday.info` | Published at launch |
| Native symbol | QDAY | QDAY |
| Decimals | 18 | 18 |

:::warning[Verify before you connect]
Always verify RPC, chain ID, and addresses against this page — not against a chat message or a random dApp banner.
:::

Add via wallet UI: [Add QDay to your wallet](/guide/start/add-network). Programmatic connect: [Wallet Integration](/Knowledge/technical/developer-guide/wallet-integration). Tokens: [Token list](tokens).

## Manual setup (EIP-3085)

```json title="QDay Aevum testnet (44005)"
{
  "chainId": "0xABE5",
  "chainName": "QDay Aevum",
  "rpcUrls": ["https://rpc-test.qday.info"],
  "blockExplorerUrls": ["https://explorer-test.qday.info"],
  "nativeCurrency": { "name": "QDAY", "symbol": "QDAY", "decimals": 18 }
}
```

`chainName` `QDay Aevum` is the network name added by the in-docs **Add QDay Aevum Testnet to Wallet** button and the name shown in wallets.
