# SDK Reference

| Package | Language | Use |
|---------|----------|-----|
| `@qday-io/sdk` | TypeScript / JavaScript | Smart Accounts, bundler, payments, agents |
| `@qday-io/sdk/payments` | TypeScript | Invoices, checkout, subscriptions, streams, webhooks |
| `@qday-io/sdk/aa` | TypeScript | ERC-4337 accounts and session keys |
| `@qday-io/sdk/agent` | TypeScript | On-chain agents (MCP + intent registry) |
| `github.com/qday-io/qday-go-sdk` | Go | Same surface for Go services |
| `qday-sdk` (crates.io) | Rust | Same surface for Rust |
| `qday-sdk` (PyPI) | Python | Same surface for Python |
| `@qday-io/cli` | CLI | `npm install -g @qday-io/cli` — [CLI Reference](/Knowledge/technical/reference/cli-reference) |

```bash
npm install @qday-io/sdk
```

Examples: [SDK & Code Examples](/Knowledge/technical/developer-guide/sdk-code-examples). Repositories: [github.com/qday-io](https://github.com/qday-io).
