# Developer Program

The QDay Aevum Developer Program provides:

- Early access to testnet and developer APIs
- Technical support via Discord and GitHub Issues
- Grant funding for projects building on QDay Aevum's four pillars (ZK, ML-DSA-65, ERC-4337, AI Agent Payment)
- Co-marketing and ecosystem visibility for launched projects

Apply via the [QDay Aevum developer portal](https://qday.io) or reach out in the `#developers` channel on Discord.
