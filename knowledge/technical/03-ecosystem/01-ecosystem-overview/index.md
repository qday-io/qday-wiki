# Ecosystem Overview

QDay Aevum is an EVM-compatible, quantum-resistant Layer 2. Its ecosystem is designed around four application pillars:

1. **Rollup Infrastructure** — fast, low-cost transactions on a Polygon CDK Layer 2, verified by multiple independent validators (M-of-N) with finalized state roots committed to Abelian's quantum-resistant Layer 1
2. **Post-Quantum Accounts** — ML-DSA-65-based accounts and wallets for Phase 2 (Aevum testnet 2027 Q2; mainnet 2027 Q4)
3. **Account Abstraction** — ERC-4337 Smart Accounts for gasless UX, session keys, and programmable authorization (agent wallets / session keys live on the Aevum testnet; mainnet Q1 2027)
4. **AI Agent Payments** — a payment stack designed for machine-to-machine commerce and autonomous agents

Every ecosystem component is designed to be backward-compatible with existing Ethereum tooling.
