# SDK & Code Examples

The QDAY SDK ships with examples in multiple languages. Full example repositories are at [github.com/qday-io](https://github.com/qday-io).

## JavaScript

```bash
npm install @qday-io/sdk
```

CommonJS entry: `require('@qday-io/sdk')`.

## TypeScript

```bash
npm install @qday-io/sdk
```

ESM + types: `import { … } from '@qday-io/sdk'`. Wallet, contract, and payment snippets on this site are TypeScript-first.

## Go

```bash
go get github.com/qday-io/qday-go-sdk
```

## Rust

```bash
cargo add qday-sdk
```

Crate: `qday-sdk` on crates.io.

## Python

```bash
pip install qday-sdk
```

Package: `qday-sdk` on PyPI.
